## Requirements

### Requirement: SVG export

The editor SHALL export the artwork as a vector SVG whose paths are generated by the same geometry
engine as the canvas preview, with user-scalable dimensions, an option to include or omit the
background, and a viewBox that covers the full grid.

#### Scenario: Vector output

- **WHEN** the user exports SVG from a 32×32 document
- **THEN** the file contains `<path>` elements in a viewBox of `0 0 32 32` (plus optional
  background rect) and no raster image data

### Requirement: PNG export

The editor SHALL export PNG rasters at an arbitrary pixel size chosen by the user, rendering the
same geometry as the preview. Each side SHALL be clamped to 1–5000 px; when no explicit size is
set the default SHALL be 8 px per cell (clamped to the limit). A lock SHALL keep the width/height
ratio equal to the canvas proportions when enabled (the default).

#### Scenario: Arbitrary size

- **WHEN** the user enters 1200×720 for a document and exports PNG
- **THEN** the downloaded image is exactly 1200×720 pixels

#### Scenario: Limit clamped

- **WHEN** the user types 9999 into the width field
- **THEN** the value is clamped to 5000 before export

### Requirement: Project save and load

The editor SHALL save the full document (grid, sub-cell factor, cells, connectors, palette, style,
metaball and background settings) as a JSON file and load such files back, restoring an identical
editing state.

#### Scenario: Round trip

- **WHEN** a project is saved and reloaded
- **THEN** the grid content, connectors, palette and style settings are identical to before saving
