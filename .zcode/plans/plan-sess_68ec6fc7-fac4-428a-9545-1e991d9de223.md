## Фаза 0. Информационная плашка про выделение (быстрый выигрыш)

Поведение сохраняем (глобальный стиль = стили красят весь холст, элементов нет), но убираем молчаливость:

1. **Тост на холсте** (`CanvasStage.tsx`): клик инструментом «Выделение» по закрашенной клетке, когда `cellObj` пуст и `styleScope === 'global'` → всплывающая плашка (~4 сек) над холстом: «Стиль применяется ко всему холсту — выделение фигур отключено. Переключите стиль на „за штрихом“, чтобы выделять и двигать фигуры» + кнопка «Переключить» (`setStyleScope('element')`). Локальный `useState` + таймер, без нового стора.
2. **Статичная подсказка** в секции «Стиль пикселей» (`SettingsPanel.tsx` под чипами скоупа, когда глобальный): тот же текст одной строкой (`text-[10px] text-muted`, паттерн `fill.selection.hint`).
3. i18n-ключи `select.scopeHint*` в en.ts + ru.ts.

## Фаза 1. Инструмент «Солнце» (`sun`)

Регистрация по чек-листу шестерёнки: `ShapeToolId`+`SHAPE_TOOLS` (shapes.ts), `Tool`+`ToolOpts`+дефолты (store.ts), иконка+хоткей `4` (ToolRail.tsx), хоткей (App.tsx — вторая карта!), i18n (`tool.sun`, `tool.sun.desc`, `opt.sun*`), case в onPointerDown (CanvasStage.tsx), явная ветка настроек **до** fallthrough-ветки шестерёнки, тесты. Превью и симметрия подхватятся автоматически (`isShapeTool`).

Геометрия — обобщение шестерёнки в `boxShapePolylines`: несколько замкнутых полилиний (как concentric): диск ядра + N лучей. Параметры (`ShapeOpts`/`ToolOpts`, всё с клампами):

| Параметр | Диапазон | Смысл |
|---|---|---|
| `sunRays` | 3..32 (12) | количество лучей |
| `sunCore` | 0.02..0.45 (0.18) | радиус круга-ядра («внутренний радиус») |
| `sunRayBase` | 0.02..0.49 (0.2) | радиус основания лучей |
| `sunRayLength` | 0.3..1 (1) | длина лучей до внешнего радиуса (0.5 = бокс драга, «внешний радиус») |
| `sunAlternate` | 0..1 (1) | множитель длины каждого второго луча (1 = все равные) |
| `sunTaper` | 0..1 (0) | сужение луча к кончику: 1 = прямоугольник, 0 = треугольник, 0.5 = трапеция |
| `sunWidth` | 0.1..1 (0.55) | доля сектора, занимаемая лучом по углу |
| `sunWave` | 0..1 (0) | волнистость луча (0 = прямой) |
| `sunWavePeriods` | 1..8 (2) | число изгибов вдоль луча |
| `sunTwist` | −1..1 (0) | спиральный изгиб (прогрессивный поворот луча) |
| `sunRotation` | 0..359 | поворот |

Волновой луч: центральная линия — радиус от base до tip с синус-поперечным смещением `sunWave·sin(t·periods·2π)` (математика как в `wavePolylines`, но в полярных координатах) + `sunTwist·t` к углу; ширина сужается по `sunTaper` (левая/правая кромки = центральная линия ± половина ширины). В настройках — чипы-пресеты «Прямоугольные/Треугольные» (ставят taper 1/0) + слайдеры; кнопка не нужна. Тесты: укладка в бокс, замкнутость контуров, клампы, число вершин от параметров.

## Фаза 2. Инструмент «Bento Grid» (`bento`)

Бокс-инструмент, выдающий N скруглённых прямоугольников-ячеек, разделённых полосами фона. Параметры:

| Параметр | Диапазон | Смысл |
|---|---|---|
| `bentoCols` / `bentoRows` | 1..8 (3×3) | число ячеек |
| `bentoGap` | 0..0.3 (0.08) | ширина разделяющей полоски |
| `bentoRadius` | 0..0.5 (0.15) | скругление углов ячеек |
| `bentoInset` | 0..0.2 (0) | отступ сетки от бокса |
| `bentoChaos` | 0..0.3 (0) | детерминированное (от seed) смещение разделительных линий — ячейки разных размеров |
| `bentoMerge` | 0..1 (0) | вероятность склейки соседних слотов (детерминированный union-find от seed) — настоящие bento-спаны |
| `bentoSeed` | число | кнопка «Перебросить» (seed+1) для новой раскладки |

Детерминированный PRNG от `bentoSeed` — превью стабильно между кадрами. Общий хелпер `roundedRectPolyline(x0,y0,x1,y1,r)` (углы — сэмплированные дуги) — переиспользуется в фазе 3. Регистрация та же, хоткей `5`. Вся сетка — один элемент (двигается целиком, как группа в AI).

## Фаза 3. Детальные настройки существующих фигур

Два общих механизма в shapes.ts + разделяемые опции (паттерн переиспользования ручек уже принят: `chevron`→`crossThickness`):

- `roundedPolyline(points, r)` — скругление вершин замкнутой полилинии дугами → опция **`shapeCorner`** (0..0.5) для `rect`, `diamond`, `polygon`, `star` (кончики).
- `bulgePolyline(points, a)` — прогиб рёбер наружу/внутрь (смещение середины ребра по нормали) → опция **`shapeBulge`** (−1..1: вогнутость ↔ выпуклость) для `rect` (пухлый/вдавленный), `diamond` (ромб ↔ искра ✦).
- **`ellipsePower`** (0.4..4, 1 = эллипс) — суперэллипс для `ellipse`/`circle`: <1 заострённый, >1 сквиркл.
- `rectPoints`/`ellipsePoints` получают опциональный `opts` (сигнатуры + вызовы в CanvasStage.tsx:717-724 и ToolPreview.tsx:80-83).
- UI: слайдеры в соответствующих ветках ToolSettings; i18n `opt.shapeCorner/shapeBulge/ellipsePower`.

## Фаза 4. Заливка + обводка (как в Illustrator) — на системе элементов

Ключевая идея: **одна отрисовка фигуры = один элемент**, содержащий клетки заливки и обводки вместе; перемещение выделением уже отложенное (призрак → `moveSelection` по отпусканию). Ничего в модели данных менять не нужно — расширяется растеризация и UI.

Новое состояние стора `shapePaint` + `patchShapePaint`:
```ts
{ fill: 'none' | 'solid' | 'pattern';   // заливка: нет / цвет / дизеринг-паттерн (текущий fillStyle)
  stroke: boolean;                       // обводка вкл/выкл
  align: 'inner' | 'center' | 'outer';   // обводка внутри / по контуру / снаружи
  strokeColor: string }                  // отдельный цвет обводки
```
Дефолт `{ fill:'none', stroke:true, align:'center' }` — полностью обратно совместимо.

Растеризация в `stampShape` (CanvasStage.tsx):
1. Контур как сегодня (`shapePathPoints`).
2. **Интерьер**: на квадратной сетке — BFS с границ холста по пустым клеткам, интерьер = дополнение (контур ∪ внешность); на гекс/треугольной/радиальной — проверка «центр клетки внутри полилинии» (even-odd) по `shapePathSegments`. Хелпер в движке + тесты.
3. **Заливка**: solid → текущий цвет; pattern → `applyFillStyle` с текущим `fillStyle` (дизеринг-заливка фигур получается бесплатно). Для per-cell значений паттерна — новая action `paintCellsValues` (как `paintCells`, но значения из карты; палитра через `resolveColor` для обоих цветов).
4. **Выравнивание обводки**: штамп кистью по клеткам контура фильтруется по классификации внутренняя/внешняя сторона: `inner` — только внутрь, `outer` — только наружу, `center` — как сейчас (без фильтра).
5. Одна транзакция коммита → заливка и обводка в одном элементе (существующая атрибуция `paintCells`), симметрия — по текущей схеме перерастеризации копий.

UI: компактная группа вверху настроек каждого фигурного инструмента (`line` без заливки — только обводка): чипы «Заливка: нет/цвет/паттерн», «Обводка: вкл/выкл», «Обводка: внутри/центр/снаружи», `ColorInput` цвета обводки; подсказка, что паттерн настраивается в инструменте «Заливка». Плюс **авто-выделение** нарисованной фигуры в scope «за штрихом» (после коммита фигурного штриха `selection = [новый id]`) — сразу можно двигать/перезаливать без лишнего клика.

## Порядок работ и проверка

Фазы 0 → 1 → 2 → 3 → 4 (движковое сначала, архитектура заливки — в конце). После каждой фазы: `npm run build` + `npm test`. Визуальная проверка в браузере в конце: Солнце во всех комбинациях (прямые/волновые/треугольные/чередование), Bento с merge/chaos/seed, скругления и выпуклости фигур, заливка+обводка во всех трёх выравниваниях + паттерн-заливка + перемещение фигуры заливки вместе с обводкой (призрак → применение), плачка при клике выделением в глобальном скоупе + переключение по кнопке.

## Заметки по границам

- `line`/`connector` — только обводка (интерьера нет); `pencil/eraser/fill/picker` не затрагиваются.
- В глобальном скоупе заливка+обводка работают, но фигура не выделяется после отрисовки — это и объясняет плашка из фазы 0.
- Хоткеи: `4` — Солнце, `5` — Bento (цифры 1-3 заняты); обновить ОБЕ карты (App.tsx и ToolRail.tsx).
- Тесты: инварианты новых фигур (укладка в бокс, замкнутость, клампы), интерьер-BFS, склейка элементов заливки+обводки.
