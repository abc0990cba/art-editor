# 12 новых инструментов-фигур + раскрывающаяся левая панель

Это пиксельный редактор: фигуры растеризуются в ячейки сетки (не векторы). Все новые фигуры рисуются перетаскиванием по bbox — как прямоугольник/эллипс, поэтому симметрия, кисть (толщина линии), undo/размер одного шага работают автоматически.

## 1. Движок — `src/engine/shapes.ts` + новый `src/engine/shapes.test.ts`

Каждая фигура определяется как **нормализованные полилинии** (вершины в координатах [0..1]), что позволяет одним кодом поддержать и квадратную сетку (целочисленная растеризация), и гекс/треугольную/радиальную (сэмплирование в doc-space):

- `shapePolylines(tool, opts)` — вершины фигуры в нормализованных координатах;
- адаптер для квадратной сетки: масштабирует в bbox, соединяет вершины через существующий `linePoints` (Брезенхем), дедуп через `Map` — по образцу `ellipsePoints`.

Новые фигуры (все — чистые функции, экспортируются и тестируются):

| Инструмент | Идея |
|---|---|
| `star` | звезда, лучи настраиваются 3–12 (по умолч. 5), внутренний радиус 0.4 |
| `polygon` | правильный n-угольник, стороны 3–12 (по умолч. 6) |
| `diamond` | ромб |
| `heart` | параметрическая кривая сердца |
| `spiral` | архимедова спираль, ~3 витка |
| `arrow` | ствол + наконечник (ломаная) |
| `lightning` | молния-зигзаг |
| `moon` | полумесяц: внешняя дуга + смещённая внутренняя |
| `wave` | синусоида ~2 периода от точки к точке |
| `cross` | плюс (12-вершинный контур) |
| `flower` | роза r = cos(k·θ), 6 лепестков |
| `gear` | шестерёнка, 8 зубьев |

Тесты `shapes.test.ts` (по стилю `geometry.test.ts`): непустота, точки внутри bbox, вырожденный случай (клик без движения), контрольные вершины (ромб — середины сторон bbox), отсутствие дублей.

- `onPointerDown` (~842): новые инструменты → `drag.kind = 'shape'`.
- Dispatch в `stampShape` для квадратной сетки (~630–635): старые инструменты — прежние fast-path (`linePoints/rectPoints/ellipsePoints`), новые — через нормализованные полилинии с параметрами из стора.
- Не-квадратная ветка (~678–696): масштабируем те же полилинии в doc-space bbox и прогоняем через существующий `sampleSeg`.
- Hover-preview (~1184–1191): включить новые инструменты.
- После расширения union — grep по `tool ===` / `case '`, закрыть все ветки (Record'ы в ToolRail подсветят пропуски на этапе компиляции).

## 4. Тулбар — `src/components/ToolRail.tsx` (обе механики, состояние persisted)

- 12 новых SVG-иконок 16×16 в стиле существующих.
- **Группа «Фигуры»**: 12 инструментов под одной кнопкой-заголовком (иконка звезды; когда активен инструмент из группы — показывается его иконка + бейдж активности). Клик по заголовку раскрывает/сворачивает список, клик по фигуре выбирает инструмент.
- **Складывание панели**: кнопка-шеврон внизу; `railOpen=false` → панель схлопывается в узкую полоску с одной кнопкой раскрытия. При сворачивании вызвать `requestFit()` (уже есть в сторе), чтобы холст перецентрировался.

## 5. Хоткеи — `src/App.tsx`

Свободные буквы: `S`=звезда, `H`=сердце, `D`=ромб, `A`=стрелка, `W`=волна, `M`=луна, `X`=крест, `K`=молния, `Q`=спираль, `N`=многоугольник, `J`=цветок, `U`=шестерёнка (конфликтов с B/E/G/I/L/R/O/C/F/Z/Y/[ ] нет). Хоткей фигуры из свёрнутой группы тоже работает — заголовок группы отразит активный инструмент.

## 6. i18n — `src/i18n/en.ts` + `ru.ts`

`tool.<id>` и `tool.<id>.desc` для всех 12 (в обоих языках; en — источник типа `Dict`), плюс ключи: группа «Фигуры», «Свернуть панель»/«Развернуть панель», «Лучи звезды», «Стороны многоугольника».

## 7. Правая панель — `src/components/SettingsPanel.tsx`

Секция «Фигуры», видимая только при активном `star`/`polygon`: слайдеры «лучи звезды» (3–12) и «стороны многоугольника» (3–12) через существующие примитивы `Section`/`Slider`.
