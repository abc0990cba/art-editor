# Grid-aware rounding for all lattices (hex, triangle, radial, …)

## Problem (verified in code)

Rounding is beautiful on the square grid but breaks on every other lattice. Four root causes:

1. **Non-tangent corner arcs** — `roundedPolygonPath` (`src/engine/geometry/poly-path.ts:12`) and `emitFilletPath` (`src/engine/geometry/outline.ts:287`) emit each corner arc with **radius = tangent length `t`**. That is geometrically correct only for 90° corners (all a square grid has). On hexagons (60° turn), triangles (120°), octagons (45°), stars and radial wedges the arc is not tangent to the edges — it wraps too far around the corner and kinks where it rejoins. Every cell edge gets two kinks → rounded hexagons collapse into a rosette/"ring alignment" pattern.
2. **No turn-angle threshold in `emitFilletPath`** — exact-collinear boundary vertices (triangle base midpoints from `builders.ts:186-199`, radial arc T-junction splits from `builders.ts:274-295`) are treated as corners; with concave radius > 0 they emit literal semicircular bumps on straight edges. Tiny arc-sample turns on radial outlines get scalloped → concentric-rings look.
3. **Rounding scale collapse on radial** — `gridPixels` (`src/engine/grids/geometry.ts:108`) uses `radius × minEdge/2`, but on radial wedges `minEdge` crosses tiny arc chords → almost no rounding (worst in inner rings), and the scale is inconsistent across grids (hex at radius 0.5 ≠ circle-like, unlike the square "Circle" preset).
4. **Clamping uses the last chord only** — fillets adjacent to an arc run (radial) are clamped to a fraction of the real edge.

## Changes

### 1. True tangent fillets in the shared core (fixes all grids at once)
- `roundedPolygonPath`: compute the turn angle θ per corner; skip |θ| < ~10° (arc samples, mirroring the existing cosine threshold); emit the arc with **radius `R = t / tan(θ/2)`, span θ** — exact tangent continuation. For 90° corners `R = t`, so **square-grid output stays byte-identical** and all existing tests hold. Chamfer style keeps the same tangent points (straight cut, unchanged).
- `emitFilletPath`: same tangency formula + θ < 10° threshold (t = 0, clean pass-through). Shared turn/arc math goes into `poly-path.ts` (outline.ts is near its ratchet cap — do not grow it past the override).
- Radius 0 paths unchanged; run-merge and staging fast paths untouched.

### 2. Corner-to-corner clamping
- In `roundedPolygonPath`, clamp `t` by arc-length distance to the neighboring **corners** (summing across arc-sample runs) instead of the adjacent chord, so arc edges don't shrink fillets.

### 3. Grid-aware rounding base in `gridPixels`
- Replace `radius * minEdge(scaled)/2` with a per-cell rounding base:
  - polygonal lattices (hex, hexFlat, triangle, rhombille, diamond, iso, brick, octasquare): min **true** edge length with collinear split vertices merged (triangle base counts once);
  - radial: `min(ring thickness, arc length at mid-ring)` via `ringSectorOf`.
  - Result: hex at radius 0.5 → circle-like, radial wedge → rounded leaf/pill, consistent with the square presets. Remove the now-dead `minEdge` helper (knip).

### 4. Radial outline + metaball audit
- Radial outline mode: with the θ threshold, fillets land only on true corners; arcs stay as sampled chords (invisible at current sampling density). Covered by structural tests, no true-arc path representation in this pass.
- Metaball on non-square grids: audit `gridMetaballField` (isotropic kernel splats vs local cell pitch — dense inner radial rings may over-merge); fix if defective and add a test; if it proves correct, document that finding.

### 5. Tests (`*.test.ts`, colocated)
- Tangency property tests: hexagon/triangle/star/octagon — emitted arc radius ≈ `t/tan(θ/2)`; path enters/exits each fillet along the edge directions.
- Per-grid structural tests across all 10 lattices: fillet counts, zero fillets at collinear/arc-sample vertices, no semicircle bumps on triangle outlines with concaveRadius > 0, radial wedge scale at radius 0.5.
- Existing suites (corner-styles, outline, geometry, runs, cell-shapes, shapes, perf-stress) must stay green unmodified — they are the square-grid regression net.
