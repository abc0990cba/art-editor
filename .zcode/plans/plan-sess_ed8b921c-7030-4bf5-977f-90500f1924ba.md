# Четвёртый воркспейс: SVG-студия (kind `svgart`) — только эффекты, совместимые с Adobe Illustrator

## Что строим

Новый вид проекта в Ditherlab: векторная сцена из фигур со стеками нативных SVG-заливок,
с ручками градиентов на холсте и световым генератором шаблонов (звезда/сфера). Жёсткое
ограничение — **экспортируемый SVG целиком состоит из подмножества, которое Illustrator
открывает как живые векторы** (цель — доводка проекта в AI без растрирования).

## Решения по совместимости (следствие вашего правила; лягут в design.md и бейджи UI)

- **Нет фильтров**: `feGaussianBlur`/`feDropShadow`/`feTurbulence` исключены — AI не сохраняет
  их надёжно как живые векторы (растр или сломанный эффект). Мягкость края/свечение/тень
  делаются **градиентным спадом `stop-opacity`** — техника star_v3.svg, доказанно живая в AI.
- **Нет `mix-blend-mode`**: AI сбрасывает CSS-свойство при импорте. Тени/блики запекаются
  в цвета стопов генератором света (как в ваших gen3.py и star_v3).
- **Нет**: `fr`, `spreadMethod reflect/repeat`, mesh (отложен из SVG 2), conic (CSS-only),
  `<mask>` (клипим через `clipPath`).
- **Да (ядро, AI-safe)**: linear/radial в `gradientUnits="userSpaceOnUse"` с **запечёнными**
  координатами (`gradientTransform` никогда не эмитится — AI его теряет), произвольные стопы
  с `stop-opacity`, стеки заливок на фигуре, `clipPath` (в т.ч. общий на группу граней),
  общие градиенты через несколько фигур (единый свет), прозрачность слоёв.
  `fx/fy` — с бейджем «проверить в вашем AI» (в сообществах фигурирует как в основном живой).
- **Эллиптический радиальный** (повёрнутый блик): без `gradientTransform` — сериализатор
  оборачивает слой в `<g transform>` с круговым градиентом в локальных координатах
  (групповые трансформации — ядро SVG 1.1, AI-safe); круговые пекутся прямо в `cx/cy/r`.
- **Бейджи AI-статуса** у каждого эффекта в UI — «чтобы вы заметили»: safe / проверить.
  Спайк: расширяем существующие `samples/ai-import-test.svg` + `docs/ai-import-test.md`
  (из изменения add-gradient-workspace) матрицей студийных приёмов для ручной проверки
  в вашем Illustrator до финализации.

## Архитектура (по прецеденту `add-gradient-workspace`)

`ProjectKind += 'svgart'`, движок `src/engine/svgart/`, слайс `src/state/svgart.slice.ts`
(вне undo, как vector/gradient), фича `src/features/svgart/`, сёрфейс в `src/app/`.
Пиксельный `Doc` не затрагивается. Worker не нужен — сериализация дешёвая.

### 1. Движок `src/engine/svgart/` (чистый TS, фасад `index.ts`)

- `types.ts` — `SvgScene {width, height, background, layers[]}`; `SvgLayer {shape, fills[],
  opacity, clipId?}`; `Shape` (rect/ellipse/polygon/star/blob); `Paint` (solid | linear
  p1/p2 | radial центр + ось A + отношение осей + фокус) со стопами `{offset, color, alpha}`.
- `oklab.ts` — OKLab↔sRGB без зависимостей: перцептуальные рампы стопов против полосатости.
- `paint.ts` — интерполяция стопов sRGB+OKLab, выпечка в hex (семантика pad как в
  `gradient/stop-colors.ts`).
- `figures.ts` — параметрические контуры → path `d` (звезда по образцу `cell-shapes/geom.ts`).
- `hit.ts` — point-in-shape и зоны ручек (чистая математика для холста).
- `softlayers.ts` — генераторы безопасных мягких слоёв: «мягкая тень», «свечение», «блик» →
  слой-эллипс с радиальным спадом (аналог shBig/shGlow/shTip из звезды).
- `light.ts` + `templates.ts` — генераторы: звезда (грани-полигоны, яркость N·L, ось
  градиента = проекция света, спекуляр/sheen — запечённые стопы; структура как star_v3.svg),
  сфера (радиальный с офсетом фокуса + спад-тень), «аврора» (стопки спад-радиалов без blur).
  Результат — обычные редактируемые слои.
- `serialize.ts` — сцена → AI-safe SVG (defs, clipPath, запечённые координаты,
  групповые transform для эллиптических радиалов); `serialize.test.ts` + золотой
  `svgart-golden.json` по образцу `texture-golden.test.ts`.
- `compat.ts` — таблица «эффект → статус AI» для бейджей UI.
- `normalize.ts` — нормализация сцены для storage round-trip.

### 2. Storage `src/storage/projects.ts`

`SvgArtProjectEntry {kind:'svgart', id, name, updatedAt, scene}`; upgrade-on-read в
`normalizeProject`; фабрика `newSvgArtEntry` (выбор шаблона). Без миграции IDB.

### 3. State `src/state/svgart.slice.ts`

По образцу `gradient.slice.ts`: сцена + selection (`selectedLayerId`, `selectedFillIndex`),
действия (`setScene`, `updateLayer`, `addShape`, `addSoftLayer`, `reorderLayers`,
`applyTemplate`…), троттлинг-автосейв, `loadSvgArtEntry`. Композиция в `editor.store.ts`
(только блок в `State` и spread — файл не разрастается).

### 4. App chrome

`project-route.component.tsx` — диспетч-ветка + `SvgArtSurface`; гейты kind в
`app-top-bar.component.tsx:49`, `top-bar-buttons.component.tsx:110`,
`top-bar-more-menu.component.tsx:163`; карточка вида + выбор шаблона в
`new-project-dialog.component.tsx`; бейдж и живой SVG-тикбнейл в `project-card.component.tsx`;
i18n-ключи `svgart.*` в `en.messages.ts` и `ru.messages.ts`.

### 5. Фича `src/features/svgart/`

- `svgart-workspace.component.tsx` — центральный stage + правая колонка `aside w-64` +
  мобильный `MobileSheet` + тулбар (фигура, мягкий слой, шаблон, экспорт/код).
- `stage.component.tsx` — живой инлайн-SVG (браузер показывает ровно то, что уедет в AI),
  оверлей выделения и ручек; pointer-события → экранные↔user-координаты → действия слайса.
- Ручки (v1): перемещение/поворот фигуры; linear — два конца оси; radial — центр, радиус,
  фокус `fx/fy`.
- `layers-panel.component.tsx` — слои: reorder, видимость, opacity, клип-группы.
- `fills-editor.component.tsx` — стек заливок: solid/linear/radial, стопы-бар (стопы,
  цвет, альфа), порядок, OKLab-рампы.
- `shape-params.component.tsx` — параметры фигуры (лучи/внутренний радиус, rx/ry, поворот).
- `soft-panel.component.tsx` — генераторы мягких слоёв (тень/свечение/блик) + бейджи AI-статуса.
- `code-panel.component.tsx` — код, копирование, скачивание; переключателя профилей нет —
  профиль всегда AI-safe (см. «Вне объёма» для будущего полного профиля).

## Этапы

1. Openspec-папка (артефакты + design.md с исследованием) + расширение ai-import-test
   спайка для ручной проверки в вашем Illustrator.
2. Движок: types/oklab/paint/figures + тесты.
3. Движок: serialize (AI-safe) + золотые тесты; softlayers; compat.
4. Движок: light/templates (звезда/сфера/аврора) + тесты структуры сцен.
5. Storage + state slice + композиция стора.
6. App chrome: маршрут, топбар, диалог создания, карточки, i18n (en+ru).
7. Фича: оболочка + stage + ручки (перемещение, ось/центр/фокус/радиус).
8. Фича: панели слоёв, заливок/стопов, фигур, мягких слоёв, код/экспорт.
9. Шаблоны в диалоге создания; ручная доводка.
10. Финал: design-review, пустые состояния, мобильные тач-цели 44px.

## Гейты качества

После каждого этапа полная цепочка: `npm run format:check` → `lint` (0 ошибок) →
`arch:check` (движок чистый, фича не импортирует другие фичи) → `knip` → `npx tsc --noEmit`
→ `npm test`. Все новые файлы ≤400 строк / ≤150 на функцию (ratchet). strict-TS:
`import type`, `obj['kind']`. Hit-test — чистая математика в движке, pointer-логика в фиче.
UI — по `.zcode/skills/design-conventions/SKILL.md`, финал — design-review.

## Вне объёма (отложенные изменения)

Фильтры (blur/glow/grain) и blend-режимы — вернуть отдельным изменением, только если
ручная проверка `samples/ai-import-test.svg` в вашем AI покажет, что они живут как векторы;
до тех пор студия их не предлагает вовсе. Также: импорт/парсинг SVG; интеграция raster2grad
(руслло существующего gradient-воркспейса); DiffVG-доводка; «полный» браузерный профиль
экспорта; mesh/conic; undo для студии; анимация.

Коммит-предложения по этапам (пишет агент, коммитит человек), например:
`feat(svgart): AI-safe engine domain for authored gradient scenes`,
`feat(svgart): studio workspace with canvas gradient handles`.
