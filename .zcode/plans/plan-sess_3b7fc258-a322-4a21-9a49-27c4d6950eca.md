Глиф-дизеринг: редактируемые тайлы по уровням тона + новые эффекты импорта

Принцип: все 23 существующих метода дизеринга (Bayer, кластеры, диффузия, Римерсма…) работают как раньше — глифы добавляются, ничего не меняется.

## 1. Ядро — `src/engine/glyph-tiles.ts` (новый, ≤400 строк)
- Типы: `GlyphTileSet { id, name, w, h, levels: boolean[][] }` — набор тайлов по уровням тона: `levels[0]` = пустой (белый), `levels[N-1]` = полный (чёрный); row-major как у кистей. Тайлы 2×2 … 8×8, уровни 5–65.
- Генераторы встроенных наборов: из любой матрицы дизеринга (`glyphSetFromMatrix(BAYER4)` → монотонная лента), растущие точки, горизонтальные/вертикальные/диагональные линии, шахматка (`BUILT_IN_GLYPH_SETS`).
- `normalizeGlyphTileSet`, `tileIndexForTone(t, levels)`, монотонная лента → пороговое поле (для будущих оптимизаций).

## 2. Импорт — два новых метода (import-image.ts, dispatch ~1073)
- **`glyph` (тональный)**: тон пикселя → индекс тайла → клетка тайла решает вкл/выкл между двумя соседними по яркости цветами палитры (расширение `mapOrdered` — палитро-независимо). 
- **`palette-glyph` (палитро-глиф)**: уровни набора = цвета палитры по яркости; цвет-кандидат остаётся, если клетка его тайла включена, иначе берётся соседний по яркости — картинка собирается из разных глифов (как pixel-art-maker).
- `ImportOptions` += `glyphSet: GlyphTileSet | null` (инлайн-копия активного набора; опции остаются сериализуемыми). `ditherStrength` — доля пикселей, идущих по тайлу vs nearest. `DITHER_GROUPS` += группа «Глифы (тайлы)».
- Все 23 метода не трогаем; новые тесты на известных градиентах.

## 3. Заливка и фигуры — паттерн 'glyph' (fillpatterns.ts)
- `FillPatternId` += 'glyph'; `FillStyle` += `glyphSet: GlyphTileSet | null`; `patternAt` case: тон (плотность/градиент) → тайл → клетка. Бесплатно работает в заливке, заливке выделения и паттерн-заливке фигур (все идут через `applyFillStyle`). Scale умножает шаг тайла.

## 4. Полутон-формы из референсов (дёшево)
`FillHtShape` += **star / heart / cross** — в screen-паттерне заливки и в текстуре фигур (`emitHalftoneDots`): звёзды/сердца/кресты вместо точек, с теми же angle/jitter/dropout.

## 5. Хранилище и стор
- `db.ts`: DB_VERSION 4 + object store `glyphTiles`; `storage/glyph-tiles.ts` — CRUD по образцу brushes.ts (`GlyphTileSetEntry`).
- Стор: `glyphSets`, `glyphSetId`, `patchGlyphSet` (ручная правка сбрасывает id на «custom» — как у кистей), `createGlyphSet/applyGlyphSet/deleteGlyphSet/renameGlyphSet`.

## 6. UI
- **`features/glyph-editor/`** — секция «ГЛИФЫ» правой панели (по образцу кистей): пиксельная сетка-редактор выбранного уровня (клик-тоггл), лента уровней-миниатюр (+/- уровень), генераторы-чипы (Bayer4/Bayer8/точки/линии/диагональ/шахматка), инверт, размер тайла, имя+сохранить, библиотека (встроенные ★ + свои), превью-градиентная полоса с живым применением набора. Файлы: `glyph-editor.component.tsx` + `glyph-tile-grid.component.tsx` + `glyph-ramp-strip.component.tsx` + `glyph-library.component.tsx` (все ≤400).
- **`shared/ui/glyph-set-picker.component.tsx`** — пикер набора + лента-превью; встраивается в import-dialog (при выборе 'glyph'/'palette-glyph') и в fill-style-controls (при паттерне 'glyph'). Идёт в shared, чтобы не нарушать запрет фича→фича.

## 7. i18n, тесты, верификация
- Ключи `glyph.*` в ru/en messages.
- Тесты: генераторы (монотонность, размеры), tileIndexForTone, patternAt 'glyph', мапперы импорта на известных градиентах; все 438 существующих остаются зелёными.
- Гейт: format → lint (новые файлы ≤400 строк / функции ≤150 — храповик) → arch:check → knip → tsc → vitest → build → smoke в браузере (импорт картинки с глиф-методом, заливка паттерном).
