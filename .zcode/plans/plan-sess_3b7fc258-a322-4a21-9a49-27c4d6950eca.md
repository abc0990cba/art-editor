Решения (по твоим ответам): kebab-case (`canvas-stage.component.tsx`), вся перестройка одним заходом, + knip, dependency-cruiser, AGENTS.md.

## 1. Целевая структура (фичи над общим ядром, без FSD)

Редактор — не CRUD-приложение, поэтому вертикали делим по UI-фичам, а домен остаётся общим ядром. Слои: `app → features → shared | engine | state | storage`, движок ничего не знает о UI.

```
src/
  app/                    # каркас: app.component.tsx (бывш. App.tsx), main.tsx, app-top-bar.component.tsx
  features/
    canvas/               # canvas-stage.component.tsx (+ разбивка, если понадобится)
    tools/                # tool-rail, tool-preview, preview-expander, fill-settings, shape-paint-controls
    nodes-editor/         # node-editor-canvas, object-graph-panel, node-preview
    layers/               # layers-panel.component.tsx
    settings-panel/       # settings-panel (правая панель)
    projects/             # projects-dialog, project-dialog
    export/               # export-popover
    import/               # import-dialog
  engine/                 # БЕЗ ИЗМЕНЕНИЙ: чистый домен (doc, shapes, scene, brush…)
                          # nodes/nodes/ расплющить → engine/nodes/{sources,transforms,ramps,repeats,styles}.node.ts
  state/editor.store.ts   # zustand-стор (бывш. state/store.ts)
  storage/                # без изменений (IndexedDB)
  shared/
    ui/                   # ui.tsx (IconButton, Slider…), tooltip, drag-number, floating-panel, color-picker, color-swatch
    lib/                  # file-download.util.ts, palette-files.util.ts
    i18n/                 # i18n.provider.tsx, en.messages.ts, ru.messages.ts (кросс-срезовая — не фича)
```

## 2. Конвенция имён (проверяется линтером)

`<kebab-base>.<тип>.<ext>`: `.component.tsx` (React-компонент), `.hook.ts` (use-хуки, `use-media-query.hook.ts`), `.store.ts`, `.provider.tsx`, `.messages.ts`, `.util.ts`, `.node.ts` (семейства нод), `.test.ts` (колокация), `index.ts` (баррель, исключение). Доменные модули движка — просто `shapes.ts` (ядро без суффиксов). Правило в oxlint: `unicorn/filename-case` с `case: "kebabCase"` (точки-суффиксы совместимы: проверяется только база до первого суффикса; index exempt).

## 3. Переезд (безопасность: копия src в /tmp, т.к. проект не в git)

Python-скрипт: карта старый→новый путь, `mv` всех ~110 файлов + рерайт всех import-спецификаторов по карте (включая относительные `../../`). Точки невозврата: после `mv` — `tsc --noEmit` обязан быть чистым до любых других шагов; далее `vitest run` (438).

## 4. Жёсткие конфиги

- **tsconfig.json** (+к существующим strict-флагам): `noUncheckedIndexedAccess`, `noImplicitOverride`, `noPropertyAccessFromIndexSignature`, `forceConsistentCasingInFileNames`. `exactOptionalPropertyTypes` пробуем; если завалит React 19-типы — фиксим реальные места, а не отключаем.
- **.oxlintrc.json** (новый, oxlint обновить до 1.85): plugins `[unicorn, typescript, react, oxc, import, vitest, jsx-a11y]`; категории: `correctness/suspicious/pedantic = error`, `style/restriction = warn`; правило filename-case. Прогон, триаж: шумные pedantic-правила точечно глушим в конфиге с комментарием, код честно чиним. Скрипты: `lint` (как есть), `lint:ai": "oxlint -f agent src"` (токен-минимальный вывод для AI-петли).
- **.dependency-cruiser.cjs**: границы — `engine` не импортирует ничего из `state/storage/features/shared/app`; `storage → engine` only; `state → engine+storage`; `features → {shared, engine, state, storage}` и **features ↔ features запрещены** (общее поднимается в shared); `app → всё`. Скрипт `arch:check`. 4 engine-теста, импортирующие store, — исключение только для `*.test.ts` (зафиксировано в правиле).
- **knip.json**: неиспользуемые экспорты/файлы/зависимости, скрипт `knip`. Триаж результата (в легаси будут находки — чиним реальный мусор, легитимное — в ignore-список).

## 5. AGENTS.md + README

`AGENTS.md` в корне: конвенции (нейминг, слои и что куда класть, запрет cross-feature импортов), порядок фидбэк-лупа для AI: `npm run format:check → lint (или lint:ai) → arch:check → knip → tsc → test`. README — те же команды.

## 6. Финальная верификация

`oxfmt` (sortImports переразложит импорты после рерайта) → `lint` 0 ошибок → `arch:check` зелёный → `knip` триажнут → `tsc --noEmit` → `vitest run` 438 зелёных → `vite build` собирается. Браузерный smoke (приложение открывается, инструменты работают).
