# Ноды как основное представление: рисуешь → сразу ноды, полная синхронизация

## Ключевое семантическое правило (устраняет рассинхронизацию)

- **Граф с source-нодой = полностью процедурный**: краска объекта игнорируется, всё генерируется параметрами нод. Двинул/перекрасил в нодах — холст мгновенно новый; «старых пикселей» не остаётся физически.
- **Граф без source (только стили/рампы/модификаторы) = краска объекта как неявный вход**: style-ноды одевают её, рампы перекрашивают, ластик и перемещение пишут через неё.
- Ластик на процедурной (source-) краске — осознанное ограничение: правьте параметры source-ноды. Это не рассинхрон (оценка всегда выигрывает), а документированное правило; в `docs/nodes.ru.md` опишу.

## 1. Живой граф у каждого нарисованного объекта (авто-присоединение при коммите)

- **Фигуры** (rect/ellipse/line + все SHAPE_TOOLS): при коммите рисуется **параметрический source-граф** — `source.rect/ellipse/line/shape` с реальными координатами перетаскивания (x/y/w/h или x0/y0/x1/y1) и полным набором ShapeOpts (starRays…ringThickness — значения из toolOpts на момент рисования) → точное воспроизведение нарисованного. Все ShapeOpts-ключи 1:1 совпадают с ToolOpts.
- **Одноцветное условие**: параметрический граф создаётся, когда фигура однотонная (только контур ИЛИ только заливка). Двухцветные (заливка+контур) и паттерны → offset-граф: базовая краска сохраняет точный вид, нули рассинхрона.
- **Карандаш / заливка / импорт-заливки**: `mod.offset (dx:0, dy:0)` — нода позиции; плюс в редакторе всегда видна неявная карточка **«Краска объекта»** — базовые пиксели, первый вход графа.
- **Коннекторы** остаются соединителями (вне растровых нод) — документирую.

## 2. Новые ноды

- **`source.line`** {x0,y0,x1,y1,color,mode} — параметрическая линия (linePoints + толщина кисти).
- **`source.shape` расширяется**: shape = все 21 SHAPE_TOOLS, params = полный ShapeOpts (starRays…ringThickness, ~45 полей, дефолты = DEFAULT_TOOL_OPTS).
- **`mod.recolor`** {color: hex} — перекрашивает все входные ячейки в один цвет палитры: «цвет через ноды» для свободных штрихов.

## 3. Синхронизация перемещения (canvas ↔ ноды)

`moveSelection`: для **процедурных** объектов dx/dy пишутся в **замыкающую ноду Offset** (создаётся при отсутствии) — сдвиг виден в параметрах ноды; для **style-only** графов — сдвигаются stored cells (как сейчас). Скрытые/старые пиксели не дублируются: процедурная краска пересчитывается.

## 4. Прочие записи холста — правила без рассинхрона

- Ластик/карандаш/заливка по procedure-краске: оценка всегда выигрывает → правки в cells просто не влияют (задокументировано; подсказка не нужна).
- `fillSelection` на style-only объектах работает (пишет в stored cells, стили reapplied).
- Экспорт/автосейв/undo — без изменений (граф в Doc).

## 5. UI

- `NodeEditorCanvas` + стек в `ObjectGraphPanel`: **виртуальная карточка «Краска объекта»** в начале цепочки (для графов без source), не удаляемая; провода из неё в первую растровую ноду.
- Тултипы нод Offset: «Позиция объекта — dx/dy».
- Автопоказ: после рисования объект выделяется → секция «Граф объекта» и кнопка редактора уже показывают его ноды (без «Создать граф» — он создаётся сам).

## 6. Документация

`docs/nodes.ru.md`: раздел «Рисуешь — уже в нодах» (авто-граф, Offset как позиция, recolor как цвет, правило source ⇒ процедурный, ластик-ограничение).

## 7. Тесты

- Карандаш → авто-`mod.offset`; правка dx/dy ноды сдвигает отрисованные ячейки.
- Фигура rect через paintCellsValues + parametric → source-нода с точным bbox; смена x ноды двигает рендер.
- source-граф игнорирует записи base ink (eraser) — фиксация семантики.
- moveSelection на процедурном объекте пишет dx/dy в Offset-ноду.
- mod.recolor перекрашивает все входные ячейки; source.line рисует по диагонали.
- Полный прогон (сейчас 413) + tsc + браузер: нарисовал линию → вижу её нодами → двигаю Offset → холст едет; фигура → правлю x → фигура едет.

## Порядок

1. eval.ts: правило source ⇒ процедурный.
2. sources.ts: source.line + полный ShapeOpts у source.shape; transforms.ts: mod.recolor.
3. store.ts: авто-графы в коммитах (commitStroke/paintCellsValues), moveSelection-синхронизация.
4. CanvasStage: параметрическая спецификация фигур (bbox/точки + opts + одноцветность).
5. NodeEditorCanvas/ObjectGraphPanel: карточка «Краска объекта».
6. i18n + docs + тесты + браузер.
