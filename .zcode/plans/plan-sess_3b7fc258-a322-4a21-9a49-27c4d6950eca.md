Замена Prettier → oxfmt (план одобрен, начало исполнения)

1. Преcheck: node -v (нужен ≥20.19/22.12 для oxfmt 0.70), yarn --version.
2. `yarn add -D oxfmt` → `yarn remove prettier`.
3. `npx oxfmt --help` → точные имена опций; удалить `.prettierrc.json`, создать `.oxfmtrc.json` со МАКСИМАЛЬНО строгим конфигом — все поддерживаемые опции явно закреплены (lineWidth 100, одинарные кавычки, без точек с запятой, trailingComma all + всё остальное, что умеет oxfmt: стрелочные скобки, пробелы в фигурных скобках, кавычки JSX, стиль тернарников и т.д.) — чтобы форматтер работал как жёсткий валидатор AI-кода без неоднозначностей.
4. Скрипты: `format` (oxfmt src vite.config.ts) + `format:check`.
5. Прогон по кодовой базе → `npx tsc --noEmit` + `npx vitest run` (438 тестов).
6. README: строка `npm run format # oxfmt`.
