# Art Editor — 7 Feature Improvements

All work is in the Vite + React 19 + zustand + Tailwind v4 app under `src/`. Every user-visible string goes into **both** `src/i18n/en.ts` and `src/i18n/ru.ts` (typed `Dict` catches missing ru keys at build). Verification: `npm run lint`, `npm test`, `npm run build`.

## 1. Custom React tooltips (replace native `title`)
There are ~96 native `title=` usages. New **`src/components/Tooltip.tsx`**: a dependency-free component that takes one child element, attaches `mouseenter/leave`, `focus/blur`, `pointerdown` handlers via `cloneElement`, and after a ~350 ms delay renders a themed bubble (`text-[11px]`, dark bubble matching theme tokens, max-w-56) through `createPortal(document.body)` at `getBoundingClientRect()`-derived fixed coordinates, flipping above/below by available viewport space. Hides on scroll/resize (capture listener). No native `title` remains.

- **`src/components/ui.tsx`**: `Chip`, `IconButton`, `Slider`, `CheckRow`, `ColorInput` keep their `title` prop but render `Tooltip` instead of the attribute — most of the 96 call sites keep working unchanged.
- Convert raw `title=` elements in `TopBar.tsx`, `ToolRail.tsx`, `SettingsPanel.tsx`, `BrushSection.tsx`, `PresetsDialog.tsx`, `ProjectsDialog.tsx`, `CanvasStage.tsx` (fit button) to `Tooltip` wraps (or `IconButton`/`Chip` where they fit).
- Fill missing hints: EN/RU language buttons, metaball quality chips (title is currently on the wrapper), ColorPicker wheel/bar/hex input, PresetsDialog close ✕.

## 2. +15 built-in config presets
Extend `BUILTIN_PRESETS` in `src/engine/presets.ts` 8 → 23 via the existing terse `builtin()` helper (validation/normalization free). New ids: `vaporwave` (square/outline/mirrorY), `circuit` (outline corner-bridge, greens), `ice-garden` (hex, circle pixels), `ember-field` (radial metaball), `film-noir` (1-bit monochrome), `candy-rush` (triangle grid), `terminal` (phosphor green), `pastel-hex` (hex rounded), `sunflower` (radial grid + radial sym), `chalk-outline` (light bg outline), `aurora` (hex metaball cool), `pixel-dungeon` (Sweetie 16 square), `koi-pond` (soft metaball), `stained-glass` (outline, dark gaps), `dither-study` (2-color checker style). Cover all 4 grid types, 3 render modes, varied symmetry/styles. Add `presetName.builtin.*` keys (en+ru). List UI already scrolls.

## 3. Arbitrary-size PNG export (max 5000 px)
- `src/engine/png.ts`: change `renderPng(doc, scale, includeBg)` → `renderPng(doc, size: { width; height }, includeBg)`; canvas exactly `width×height`, `ctx.scale(width/w, height/h)`. `renderThumbnailDataURL` unchanged.
- Store: replace `pngScale/setPngScale` with `pngWidth/pngHeight: number | null` (`null` = auto = current canvas × 8, clamped) + `setPngWidth/setPngHeight` clamping to **1..5000**.
- `SettingsPanel` export section: replace the 1×–16× `<select>` with width/height px inputs (clamped, integers), an aspect-lock toggle (default on — editing one field recomputes the other from doc aspect), and a live "N×M px" readout. Update `openspec/specs/export/spec.md` PNG requirement accordingly.

## 4. Exactly one current brush
Store keeps a single `brush`, but row highlighting matches by *content* (`sameBrush`), so two identical presets can both look active and edits detach highlight arbitrarily. Fix: add `brushId: string | null` to the store (`'builtin.px1'` initially; `null` = custom). `applyBrushPreset(id, brush)` sets both; `patchBrush` resets `brushId: null`. `BrushSection` highlights `brushId === p.id` only — single selection guaranteed — and shows a small "Custom" row/label when `brushId === null`.

## 5. RGB / CMYK / HSV color choosing
- `src/engine/color.ts`: add `CMYK {c,m,y,k}` (0..1) + `rgbToCmyk`/`cmykToRgb`/`hexToCmyk`/`cmykToHex` (standard k = 1−max(rgb) formula, divide-by-zero safe).
- `ColorPicker.tsx`: segmented mode tabs **HSV | RGB | CMYK**. HSV tab = existing wheel + brightness bar; RGB tab = R/G/B sliders (0–255 with numeric readouts); CMYK tab = C/M/Y/K sliders (0–100%). Internal truth stays HSV; sliders convert through rgb→hsv. Hex input + preview swatch shared below. New i18n keys `picker.hsv/rgb/cmyk`, channel labels.

## 7. Cursor position / pixel index readout
`CanvasStage` already tracks `hover.idx` (buffer cell index). Extend `Hover` to `{ idx, bx, by }` (computed in `onPointerMove`; `bx = idx % bw`, `by = idx / bw | 0`). Status pill (bottom-right, next to zoom) gains a monospace readout: square grids show `x:12 y:34 · i:298`; hex/triangle/radial show `i:298`; `—` when the cursor is off-canvas. Tooltip explains the index (buffer cell index, sub-cell aware).
