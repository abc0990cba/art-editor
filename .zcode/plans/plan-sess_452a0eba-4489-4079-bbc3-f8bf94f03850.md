# Landing page + SEO for Ditherlab — static multi-page build on the current stack

**Approach (per your answers):** a hand-rolled static landing at `/` (ru) and `/en/` (en, hreflang-linked), the editor app moved to `/editor`, built with Vite's native multi-page support — **zero new runtime dependencies, no SSG framework**. Artwork is generated by your own engine (`buildSvg` is a pure Node-safe function). Rewrite configs included for Vercel/Netlify/CF Pages; domain left as a clearly-marked placeholder until you have one.

## 1. OpenSpec change (repo convention)
- Create `openspec/changes/add-landing-seo/` — proposal.md (explicitly reverses the "SSR/SEO non-goal" recorded in `add-project-home/proposal.md:51`), design.md, tasks.md, and a spec delta for a new `landing-page` capability.

## 2. Vite multi-page + editor moves to `/editor`
- `editor.html` (new — the current `index.html` content): same `/src/app/main.tsx` script, plus favicon links, `theme-color`, and `meta robots noindex` (the app has no crawlable content).
- `vite.config.ts`: `build.rollupOptions.input` = `{ main: 'index.html', en: 'en/index.html', editor: 'editor.html' }`.
- A ~15-line inline Vite plugin with `configureServer` + `configurePreviewServer` middleware mapping `/editor` and `/editor/*` → `/editor.html`, so dev, preview and production behave identically.
- `src/app/router.tsx`: add `basepath: '/editor'` to `createRouter`. Routes stay `/` (projects home) and `/p/$projectId` — deep links become `/editor/p/<id>`.
- Bench URL becomes `/editor/?bench=1` — update mentions in AGENTS.md, README.md, docs.

## 3. Landing pages (`index.html`, `en/index.html`, `landing/`)
- Full static HTML (crawlers see final markup), Tailwind utilities on the existing design tokens; `landing/landing.css` imports `src/index.css` so all 7 themes work via `data-theme`.
- ~6-line inline head script sets `data-theme` from the `glyph.theme` localStorage key (auto → `prefers-color-scheme`) — no flash, matches the app theme.
- `landing/main.ts` (small, type-checked, added to knip/tsconfig entries): language links write `glyph.lang` before navigating between `/` and `/en/`, so the app opens in the chosen language.
- Content (ru + en, from README copy): hero + "Open editor" CTA → `/editor`, engine-generated posters, feature sections (4096×4096 canvas, ~30 tools, 22 dither fill patterns, photo import with 23 dithering algorithms + 22 palettes, 28 cell shapes / metaball / outline render modes, symmetry suite, node graphs, vectorizer & gradient workspaces, SVG/PNG/JSON export, local-first with no sign-up, 7 themes + ru/en), footer.
- Landing copy lives in the two HTML files by design (not in the app i18n dictionaries — crawlers must see final text); app dictionaries untouched.

## 4. Engine-generated artwork + assets
- `scripts/generate-landing-art.ts`: builds 3–5 demo docs (reuse the demo-project factories if Node-safe, else engine constructors) → `buildSvg()` → writes committed `landing/art/*.svg`; run with `tsx` (one new devDependency).
- `public/favicon.svg` + `apple-touch-icon.png`; `public/og.png` (1200×630 poster + wordmark, one-off render); `public/manifest.webmanifest` (icons, `start_url: /editor/`).

## 5. SEO head + crawler files
