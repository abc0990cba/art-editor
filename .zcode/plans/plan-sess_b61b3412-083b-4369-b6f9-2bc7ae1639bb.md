# План: расширение дизеринга, палитр и пресетов (по мотивам Dither Guy / Dither Boy)

Исследование: из исходников Dither Guy взяты точные таблицы 21 алгоритма, 12 палитр и pre/post-конвейер; из Dither Boy — Glow, аберрация, пресеты, стек эффектов. Так как `convertImage` кладёт результат в сетку ячеек → `buildGeometry` → SVG/PNG, **все новые эффекты автоматически получают векторный SVG-экспорт** — ничего дополнительно делать не нужно.

## Фаза 0 — OpenSpec change
- Создать `openspec/changes/expand-dither-toolkit/` (proposal.md, specs deltas: import-image, palettes, presets, tasks.md) по конвенции репозитория.

## Фаза 1 — движок дизеринга (`src/engine/`)
- **Новый `ditherMatrices.ts`** (общий модуль матриц): `CLUSTER_4X4`, `HALFTONE_4X4`, `BLUE_NOISE_8X8`, `VOID_CLUSTER_8X8`, `PATTERN_8X8`, процедурный `crosshatch(x,y)`, Bayer 16×16. `fillpatterns.ts` (`expandBayer`/`bayerAt`) переводится на него без изменения поведения.
- **`importImage.ts`:**
  - `ImportDither` += `sierra, sierra-lite, stucki, burkes, jjn, stevenson-arce, nakano, ostromoukhov, variable-error, dot-diffusion, riemersma, clustered-dot, halftone, blue-noise, void-cluster, crosshatch, pattern, bayer16` (итого ~24 режима).
  - Обобщённый `mapErrorDiffusion` на таблицах коэффициентов (dy, dx, вес) — точные веса из `dither_kernels.py` Dither Guy; Floyd/Atkinson переводятся на таблицы (байт-в-байт тот же результат), serpentine для всех.
  - Особые: Ostromoukhov (таблица 32 яркостных полос), Variable-Error (масштаб ошибки от яркости), Dot-Diffusion (классы точек), Riemersma (буфер 16, decay 1/16).
  - Ordered — через существующий `mapOrdered` + новые матрицы; crosshatch — процедурный порог.
  - `ImportOptions` += `ditherStrength` 0–100 (default 100; diffusion: ошибка × strength/100; ordered: сдвиг (matrix−128)×strength; 0 = чистый nearest) и `threshold` 0–255 (default 128, для 2-цветных палитр и ordered).
- **Бонус:** новые матрицы (`halftone`, `clustered-dot`, `blue-noise`, `void-cluster`, `crosshatch`) добавить и в `FillPatternId` заливки — почти бесплатно после общего модуля.
- Тесты: детерминизм, `strength=0` ≡ nearest, характерные паттерны, идентичность FS/Atkinson текущей реализации.

## Фаза 2 — pre/post-конвейер
- **Новый `imageOps.ts`** (чистые функции RGBA): gaussianBlur, sharpen (unsharp), hueRotate, medianDenoise, smooth, `glowScreen` (screen-blend: out = base + glow·k − base·glow·k/255 — аналог Epsilon Glow), `chromaticAberration` (сдвиг R/B каналов).
- Порядок в `convertImage`: resample → яркость/контраст/сатурация (уже есть) → blur → sharpen → hue → preDenoise → preSmooth → аберрация → дизеринг (+blend палитры) → glow → повторный snap в `nearestIndex` → postDenoise → postSmooth → snap.
- `ImportOptions` += `blur` 0–10, `sharpen` 0–100, `hue` −180…180, `preDenoise/preSmooth/postDenoise/postSmooth` 0–5, `glowRadius` 0–24, `glowIntensity` 0–100, `aberration` 0–12.
- Юнит-тесты каждой операции + интеграционный тест конвейера.

## Фаза 3 — палитры
- **`palettes.ts`:** + 8 ретро-палитр из Dither Guy (RGB-значения из `palettes.py`): B&W, Game Boy Pocket, NES, ZX Spectrum, CGA Mode 4, Macintosh, Teletext, Gruvbox (Game Boy, C64, PICO-8 уже есть) + i18n `palette.*` en/ru.
- **Blend:** `expandPaletteWithBlend(palette, 0–100)` — сортировка по luminance, вставка промежуточных оттенков между соседними парами; применяется только при конвертации импорта, палитру документа не меняет.
- **Новый `paletteIO.ts`:** парсинг `.hex`/`.gpl`/текста с hex-кодами, сериализация в `.hex`/`.gpl`, экспорт PNG-полосы, импорт PNG-палитры (семплинг). Кнопки Import/Export в секции Color в `SettingsPanel.tsx`.

## Фаза 4 — пресеты и UI
- **Новый `importPresets.ts`:** ~10 пресетов импорта в один клик: Game Boy (bayer4), Game Boy Pocket (sierra-lite), Newspaper (clustered-dot + denoise), Halftone Print, NES (burkes), ZX Spectrum (floyd + blend), CGA Vaporwave (crosshatch + glow + аберрация), Macintosh (atkinson), Teletext, Gruvbox (sierra + glow). Чипы пресетов сверху `ImportDialog.tsx`, валидация + тесты.
- **`ImportDialog.tsx`:** селект дизеринга с группами Diffusion/Ordered/Pattern (сейчас чипов станет слишком много), слайдеры Strength, Threshold, Blur, Sharpen, Hue, Denoise/Smooth (pre/post), Glow ×2, Aberration, Palette Blend — живое превью уже работает.
- **Встроенные пресеты редактора:** +4 в `presets.ts` на новых палитрах (Teletext, CGA Terminal, Macintosh Classic, Gruvbox Study) + `presetName.*` i18n.
- Все новые строки — в `src/i18n/en.ts` и `src/i18n/ru.ts`.

## Вне скоупа (на потом, как вы и сказали)
Видео/анимации, temporal-эффекты, batch-обработка, JPEG-glitch, новые форматы экспорта (MP4/JPEG).

## Реализация
Работы выполнить одним OpenSpec-изменением `expand-dither-toolkit` по фазам выше; порядок фаз последовательный (каждая следующая опирается на движок из предыдущей). После каждой фазы — прогон тестов.
