# Add wallpaper-group symmetry modes + ghost brush preview

## Overview

Two features:
1. **21 new symmetry modes** — the 19 from the screenshot (`p1, p1hex, p1diag, pm, cm, pg, pmg, pgg, pmm, p2, cmm, p4, p4g, p4m, p3, p3m1, p31m, p6, p6m`) plus **brick** and **half-drop** repeats. Unlike the existing finite modes (mirror/quad/radial, which act only around the canvas center), these are **repeat/tiling symmetries**: a brush point is replicated across the whole canvas via lattice translations + point-group operations (mirrors, rotations, glides).
2. **Symmetry ghost preview** — on hover, all symmetry copies of the hovered cell are drawn as translucent fills of the current color (eraser: neutral translucent fill), so you see where the brush will land before painting. Existing hover outline stays on the primary cell. Ghost is suppressed during an active stroke (the staging preview already shows the true result then).

## Part 1 — Wallpaper/repeat symmetry engine

### State (`src/engine/doc.ts:104-109`)
Extend `SymmetryState.mode` union with the 21 new names; add `cell: number` (lattice repeat size in buffer cells, default 16, clamp 4–64). This matches the screenshot's "grid adjust / ½ / 2x" row.

### Transform math (`src/engine/symmetry.ts`)
New wallpaper engine alongside the existing switch:
- `isRepeat(mode)` helper. Each group is defined as: **lattice basis** (square for p1/pm/pg/pmm/pmg/pgg/p2/p4-family and cm/cmm; hexagonal 60° basis for `p1hex, p3, p3m1, p31m, p6, p6m`; diagonal 45° basis for `p1diag`; centered rectangular offsets for `brick` (rows offset ½ cell) and `halfdrop` (columns offset ½ cell)) plus **affine op table** in lattice-fractional coords — e.g. pg = identity + glide `(x,y) → (−x, y+½)`; p4m = 4 rotations + 4 mirrors; cm/cmm include the (½,½) centering translation. Op tables taken from standard wallpaper-group presentations and pinned by tests.
- Orbit enumeration for brush point p: for each op, transform p, then add all lattice translations whose result lands in-bounds. Translation ranges are computed via the dual-basis projection of the buffer rectangle so candidates ≈ orbit size (no wasteful full-grid scans).
- Refactor the dedupe from the current O(n²) `out.some()` scan to a `Set` keyed `y*bw+x` (wallpaper orbits can reach hundreds of points). Add a safety cap (~4096 points/orbit) for pathological tiny-cell settings.

### Integration points
- `expand()` (`CanvasStage.tsx:204-231`) and `stampShape()` (`:301-305`) already funnel square-grid cells through `symmetryPoints(...)`, so the new modes work automatically for pencil, eraser, and shapes on the **square grid**. On hex/triangle/radial grids the new modes fall through to no-op (same as existing mirror modes there today).
- Fill tool and connector remain non-symmetry (unchanged behavior, noted to user).
- `drawGuides()` (`CanvasStage.tsx:33-77`): for repeat modes draw the lattice cell grid (parallelograms for hex/diag/brick), plus dashed mirror/glide axes for groups with reflections (pm, cm, pmm, pmg, pgg, cmm, p4m, p4g, p3m1, p31m, p6m).

### UI / i18n / presets / store
- `SettingsPanel.tsx:374-396`: restructure the Symmetry section into labeled rows — **Basic** (none, mirrorX, mirrorY, quad, diag8), **Rosette** (radial, kaleido + existing Folds slider), **Wallpaper** (19 group chips, compact grid; labels are the group symbols themselves, no translation needed) and **Repeat** (brick, half-drop). When a repeat mode is active: **Cell size** slider (4–64) + **½ / 2x** buttons (screenshot's "grid adjust" row). Keep "Show guides".
- i18n `en.ts` / `ru.ts`: new keys `sym.basic`, `sym.rosette`, `sym.wallpaper`, `sym.repeat`, `sym.cell`, `sym.half`, `sym.double` (EN+RU).
- `presets.ts`: extend `SYM_MODES` (line 37), normalize/clamp `cell` (lines 110-116). Existing presets stay valid (old modes still in the union; missing `cell` defaults to 16).
- `store.ts:157`: default symmetry gets `cell: 16`.

### Tests (`src/engine/symmetry.test.ts`)
- p1 tiles point at exact `(x±cell, y)`, `(x, y±cell)` offsets; brick rows offset ½ cell; halfdrop columns offset ½ cell.
- pm/pmm mirror images per tile; pg glide copy at `(−x, y+½)`; p4 quarter-turns; p6/`p1hex` 60° rotation stays on the hex lattice.
- Closure check: applying each group op to any orbit member yields a member of the orbit (within rounding).
- Existing mode tests keep passing.

## Part 2 — Ghost preview (`CanvasStage.tsx` render effect, after line 653)

When `hover` is set, no drag is active, symmetry mode ≠ none, and tool is pencil/eraser (shapes get no hover ghost — nothing is defined before dragging; during a stroke the staging preview shows reality):
- Compute `expand(hover.idx)`; for each **secondary** point fill the cell rect (square grid) or `grid.polygon` (others) with the current color at ~35% alpha; for eraser use the theme hover color at ~25% alpha.
- Draw before the existing hover outline so the primary cell outline stays crisp.
- Always on when symmetry is active (per your choice — no extra toggle).

## Known limits (will state in delivery)
- Repeat modes are square-grid only; on hex/triangle/radial grids they behave like "none" (matching today's mirror-mode behavior there).
- Fill and connector tools don't participate in symmetry (pre-existing behavior).
