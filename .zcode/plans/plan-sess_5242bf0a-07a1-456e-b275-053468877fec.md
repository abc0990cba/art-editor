# План: режимы рисования сегментов окружности + опция прямых краёв + авто-Fit и селектор размеров

## 0. Ранее спланированное (включено по подтверждению)

1. **Авто-Fit при смене пресетов**: вызов `requestFit()` после `setSize(n,n)` в шапке, после `applyPreset(p)` в `SettingsPanel.tsx:175` и в `PresetsDialog.tsx:47` (механизм: `store.requestFit` → `fitSignal` → `CanvasStage.fit()` уже пересчитывает вьюху от новых размеров холста). Внутрь сторовых `setSize`/`applyPreset` не кладём — иначе Fit срабатывал бы на каждое нажатие клавиши в полях W/H.
2. **Селектор размеров холста**: в `TopBar.tsx:53-64` ряд чипов 32/64/128/256/512 → один нативный `<select>` (опции `32×32`…`512×512`; если текущий размер не пресет — доп. опция `WxH`); стиль как у полей W/H; `onChange` = `setSize` + `requestFit()`.

## 1. «Равные ячейки на кольцах» — опция радиальной сетки

Сейчас `makeRadial` (`src/engine/grids.ts:286-343`) даёт одинаковое число секторов на всех кольцах — внутренние ячейки узкие. Добавляем:

- Поле `radialEven: boolean` в `Doc` (default false) + переключатель `CheckRow` в секции сетки `SettingsPanel` (виден только при `gridType === 'radial'`).
- `makeGrid`/`makeRadial` получают флаг (в ключ кэша тоже): в режиме even число секторов кольца `S_r ∝ (r+0.5)`, нормировано на выбранный `cols` на внешнем кольце, минимум ~3. Индексация — через массив кумулятивных смещений `ringStart[r]` (`ringOf`/`sectorOf`); `center/polygon/cellAt/angleOf/radiusOf` считаются от per-ring counts. `byAngle`/`cellByAngle` и `attachEdgeMap` уже родовые — работают без изменений, рендер `gridGeometry` идёт по полигонам.
- Переключение перестраивает doc через `convertGridDoc` (он переносит рисунок поточечно, `makeGrid` для старой сетки вызвать с её флагом) — undo/автосохранение работают как у `setSize`.

## 2. Прерывистые сектора и фаза (параметры радиальной симметрии)

Новые поля `SymmetryState` (`src/engine/doc.ts:142-180`): `fill: number` (10..100, default 100 — доля заполнения сектора), `phase: number` (0..359, default 0 — поворот узора).

- `symmetryPoints`, кейс `radial/kaleido` (`src/engine/symmetry.ts:288-311`): если `fill < 100` — точки, чей угол не попадает в заполненную часть сектора (с учётом `phase`), не красятся вовсе, включая исходную (рисование становится возможным только внутри клина; симметрия replicрует его в равные клинья с промежутками).
- `symmetryTransforms` и `polarAngleMaps` — тот же фильтр/фаза для фигур и для полярных сеток.
- `SettingsPanel`: два `Slider` рядом со «Складками» (`:749-758`), видимы при `isRadial`.
- Направляющие (`drawGuides`, `CanvasStage.tsx:114-127`): дорисовать границы клина (фаза + заполнение), когда `fill < 100` или `phase ≠ 0`.

## 3. Витая (спиральная) симметрия

Поле `SymmetryState.twist: number` (−45..45, default 0 — градусов на единицу радиуса).

- В кейсе `radial/kaleido` источник `(dx,dy)` дополнительно поворачивается на `twist·r` (r = расстояние до центра) перед fold-поворотом — мазки закручиваются в спирали/вертушки. Аналогично в `symmetryTransforms`; в `polarAngleMaps` отображение угла становится `f(θ, r)` (радиус уже доступен в `expand()`, `CanvasStage.tsx:383-403`).
- `Slider` «Закрутка» в SettingsPanel при `isRadial`.

## 4. Заливка сектора и кольца (радиальная сетка)

- UI-состояние в сторе (вне undo): `fillScope: 'cell' | 'sector' | 'ring'` (default `'cell'`).
- `CanvasStage`, обработка заливки (~`:723`): при `gridType === 'radial'` и scope `sector`/`ring` сиды = все ячейки, чей средний угол попадает в угловой диапазон сектора клика (клин через все кольца) / все ячейки того же кольца (`grid.radiusOf`/`angleOf`, работает и для even-сеток); симметрийное расширение в этом режиме пропускаем (клин уже покрывает круг).
- `SettingsPanel`, секция сетки: чипы «Заливка: Ячейка / Сектор / Кольцо», видны при радиальной сетке.

## 5. Опция «прямые края у границы» (метаболлы, скругление)

Эффекты не должны трогать стороны/углы, выходящие на границу холста. Флаг отдельный для каждого стиля (чтобы пресеты захватывали его естественно): `PixelStyle.squareEdges` и `MetaballSettings.squareEdges` (default false; `doc.ts:20-43`).

- **Пиксели** — `shapeGeometry` (`geometry.ts:75-158`): обнулять радиусы углов, смотрящих на границу (`bx===0` → tl/bl, `bx===cols-1` → tr/br, `by===0` → tl/tr, `by===rows-1` → bl/br).
- **Контур** — `outline.ts` (`emitFilletPath:198-249`): пропускать скругление (радиус 0) для вершин силуэта, лежащих на линиях границы холста (передать размеры doc).
- **Метаболлы** — `buildField` (`geometry.ts:284-292`): вместо округлого «отрыва» от края — для граничных узлов поля рядом с закрашенными ячейками копировать значение внутреннего узла (≥ ISO), чтобы контур marching squares шёл прямо по границе.
- UI: по `CheckRow` в блоке скругления (`SettingsPanel.tsx:~386-407`) и в блоке метаболлов (`~521-558`) — переключается в любой момент, как просили.
- Неквадратные сетки (hex/triangle/radial рендер) — вне скоупа, флаг на них не действует.
