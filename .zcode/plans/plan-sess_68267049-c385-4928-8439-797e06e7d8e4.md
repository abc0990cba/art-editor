# Fix radial-grid rounding: adaptive arc sampling + metaball disc clamp

## Problem

The generic lattice pipeline (`src/engine/grids/geometry.ts`) already renders Outline/Metaball on radial, and commit `2d0eb50` made the rounding core tangent-correct. But radial wedge polygons (`makeRadial` in `src/engine/grids/builders.ts:262`) approximate arc edges with a **fixed `ARC = 4` samples per interval**, so each chord turns by `sectorSpan / 5`. The shared fillet core (`poly-path.ts:11`, `CORNER_COS = 0.985`) rounds any turn > ~9.9° as a true corner. Consequences:

1. **Scalloped arcs**: any ring with ≤ 7 sectors (span > 49.7°) gets false fillet bumps on every arc sample — in Outline mode (wavy silhouette), and in Pixels mode `minCornerRun` collapses to chord length so wedge rounding starves.
2. **Even-mode radial (`radialEven`) always breaks near the center**: sector counts halve down to 2 toward the center (spans up to 180° → 36° chord turns), so inner rings scallop and metaball splats shrink even at the default 32 columns.
3. **Metaball spills past the disc**: square grids clamp the field at the canvas border nodes; radial only clamps at the square bounding box, 1 unit beyond the disc — blobs bulge into the empty margin (`grids/geometry.ts:319` passes `squareEdges: false` with no substitute).
4. Ring-0 apex wedges carry duplicate center vertices but all consumers dedupe them — fine; lock with a regression test.

## Changes

### 1. Adaptive arc sampling — `src/engine/grids/builders.ts` (`makeRadial`)
Replace the constant `ARC = 4` with a per-interval sample count that is a pure function of the interval angle: `n = max(4, ceil(interval / 8°))` (8° keeps chord turns below the 9.9° corner threshold with margin; intervals ≤ 32° — i.e. every radial with ≥ 12 uniform sectors, including the default doc at 32 columns — keep `n = 4` and stay byte-identical).
- Use it in the `arcPoints` inner loop (`builders.ts:287-293`).
- Shared-arc vertex invariant is preserved: both rings derive their stop endpoints from `k·(2π/s)` products and `n` depends only on the interval, so shared pieces keep identical vertices (the existing `q6` quantization absorbs ulp noise; `interval/8°` is never an exact integer since intervals are rational multiples of π).

### 2. Metaball field clip — `src/engine/geometry/metaball-field.ts` + `src/engine/grids/geometry.ts`
- `buildMetaballField`: add optional `clip?: (x, y) => boolean` (doc units); after splatting, zero nodes where the clip fails (one O(fw·fh) pass, before the border block).
- `gridMetaballField`: for `grid.type === 'radial'` pass `(x, y) => (x − w/2)² + (y − h/2)² ≤ rows² + 1e-9` (radial `rMax = rows`, `builders.ts:261`) — the radial analog of the square border clamp; blobs now close along the disc boundary. Also applies to the diffusion-guides overlay (same builder) — consistent.

### 3. Tests — extend `src/engine/grids/geometry.test.ts` (grid-aware rounding suite)
- Outline scallop regression: even radial `cols=16 rows=8`, one wedge per ring → fillet arcs only at true wedge corners (≤ 4 nonzero-radius arcs per wedge), for every ring incl. s ∈ {2..7}.
- Pixels: inner-ring wedge (s ≤ 4) at `radius: 0.5` → exactly the true corners filleted with healthy radii (leaf shape, not chord-starved).
- Metaball flow: adjacent same-ring pair in a coarse ring (uniform `cols=6`) and in an even-mode inner ring at `strength: 60` → single merged loop.
- Metaball clamp: outer-ring splat → field is 0 beyond `rMax`.
- Ring-0 apex wedge in Outline → exactly one path, no `NaN` in path data.
- Existing radial tests use `cols=12` (intervals ≤ 30° → `n = 4`) and must stay green unchanged.
