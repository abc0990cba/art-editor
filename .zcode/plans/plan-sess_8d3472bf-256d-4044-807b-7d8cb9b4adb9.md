## Цель

1. Убедиться, что селектор (первый инструмент в левом тулбаре, клавиша `V`) работает: выделение кликом, перемещение drag'ом, смена стиля и цветов через правую панель.
2. Новая фича: для фигур, выделенных селектором, можно заменить их заливку (fill) — паттерны и цвета из инструмента fill, с мгновенным применением. Дополнительно клик инструмента fill по выделенной фигуре перезаливает её целиком.

## Текущее состояние (найдено при исследовании)

- Селектор реализован: `ToolRail.tsx` (первый в `order`), хит-тест через `doc.cellObj` в `CanvasStage.tsx:894-917`, drag → `moveSelection` (`store.ts:674`), стили выделения → `restyleSelection` (`store.ts:632`), работают при `styleScope === 'element'` (это дефолт).
- Fill: `FillStyle` (16 паттернов, 2 цвета, градиенты, плотность/масштаб/зерно) в `src/engine/fillpatterns.ts`, применяется только flood-заливкой по клику (`store.ts:495-526`). Настройки — `FillSettings.tsx` (попап по двойному клику на кнопку fill).
- Пробел: при переключении с селектора выделение сбрасывается (`store.ts:876-879`), и поменять заливку/цвет именно выделенной фигуры нельзя.

## Изменения

**1. Engine (чистая функция, тестируемая):** в `src/engine/fillpatterns.ts` (или рядом) добавить `fillSelectionCells(doc, selectionIds, style, colorA)` → собирает регион всех ячеек с `cellObj[i] ∈ selection` и `cells[i] > 0`, через существующие `applyFillStyle` + `patternCoord` + `resolveColor` возвращает новые `cells` (solid → цвет A, pattern → микс A/B). `cellObj` не трогаем — ячейки остаются в своих элементах. Работает на любой сетке.

**2. Store (`src/state/store.ts`):**
- Новое undoable-действие `fillSelection()` поверх хелпера (один шаг истории, троттлинг zundo уже склеивает быстрые правки слайдеров).
- `setTool`: сохранять `selection` при переключении на `'fill'` (сейчас сбрасывается на любом не-select).

**3. UI:**
- Вынести контролы из `FillSettings.tsx` в общий компонент `FillStyleControls` (чипы solid/pattern, галерея паттернов, градиент, масштаб, зерно, плотность, color2 + swap); сам `FillSettings` (попап тула) переиспользует его без изменения поведения.
- `SettingsPanel.tsx`: при активном выделении (element scope) — новая секция «Заливка выделения» с превью + `FillStyleControls`; любое изменение → `patchFillStyle(patch)` + `fillSelection()` (мгновенное применение, как у остальных секций стилей).
- Секция «Цвет»: обёртка `applyColor` — `setColor(h)` и, если есть выделение, `fillSelection()` — выбор цвета перекрашивает выделенные фигуры.
- `CanvasStage.tsx`, case `'fill'`: если клик пришёлся на ячейку выделенного элемента → `fillSelection()` (вся фигура/все выделенные), иначе прежняя flood-логика; hover-превью заливки для выделенной ячейки показывает весь регион выделения.

**4. i18n:** новые ключи RU/EN (`panel.fillSelection` «Заливка выделения», подсказка).
