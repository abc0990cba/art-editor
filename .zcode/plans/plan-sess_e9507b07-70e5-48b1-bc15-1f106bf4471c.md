# Texture density fixes, texture gap, natural variants, section icons

## 1. Density fixes: "fit, don't reject"
Rounded corners and metaballs lose density because flecks that fail shape containment are **rejected** — exactly at edges where grunge is densest. Fix: nudge instead of drop (this is "apply texture after the shape effect" — the texture conforms to the final geometry).
- **Pixels/outline (rounded corners):** when a fleck's box violates a corner fillet, compute the minimal diagonal shift that satisfies the arc/chamfer constraint (project the violating box corner onto the fillet), apply it, re-limit the fleck into its own mini-cell (keeps the strict no-overlap invariant), and keep it if the final containment check passes. Only impossible positions get dropped.
- **Metaball:** lower the center margin (ISO+0.3 → ISO+0.15); when the corner containment fails, nudge the fleck up to 2 steps along the field gradient (toward blob interior) and retry — boundary candidates survive, so grunge stays dense at blob edges.

## 2. Texture gap (neighbor-aware)
New `gap` field (0–0.45 of a cell, default 0) + "Edge gap" slider. Per side of each pixel:
- Side faces an **empty cell or canvas edge** → apply the gap inset (clean margin).
- Side faces **any painted neighbor** (a connection) → no inset, texture runs continuously across the join.
Applied in pixels mode and outline mode via neighbor checks (outline uses same-color `isV`); in metaball mode estimated as depth-to-contour `(field − ISO) / |∇field| < gap → skip`.

## 3. More natural variants + controls
- **`perlin`** distribution — 3-octave fractal value noise (smooth multi-scale mottling, more natural than single-octave clumps).
- **`voronoi`** distribution — seeded stain colonies: feature points on a coarse lattice, each with hashed radius/strength, specks spawn around them (organic irregular clusters).
- **`angle`** field (0–180°, default 45) + "Angle" slider for streaks (direction was previously seed-locked).
- Distribution row becomes: Scatter / Clumps / Streaks / Perlin / Voronoi.

## 4. Section icons
`Section` in `ui.tsx` gets an `icon` prop rendering a small stroke-glyph set (grid, presets/sparkle, color droplet, brush, pixel style, speckle texture, symmetry, canvas frame, export arrow). All main sections in `SettingsPanel` (and Brush) get icons for faster scanning.

## Plumbing
`doc.ts` (`gap`, `angle`, extended `TextureDist`, defaults — all backward compatible), `texture.ts` (clamps, nudges, weights, metaball gap), `geometry.ts` + `outline.ts` (per-side insets), `presets.ts` + `project.ts` (normalize/serialize), `ui.tsx` + `SettingsPanel.tsx` (icons, Edge gap + Angle sliders, 5 dist chips), `i18n/en.ts` + `ru.ts`.

## Tests & verification
- Rounded corners: fleck count with radius 0.44 stays within a tight factor of sharp-corner count (was: collapsed); determinism kept.
- Metaball: boundary ring populated (flecks within ~2 nodes of the contour exist).
- Gap: lone cell → all flecks inset by ≥ gap; adjacent cells → flecks present in the join strip.
- Perlin/voronoi deterministic, distinct, bounds-clean at size extremes; angle changes streaks; normalization/roundtrip of new fields; existing 179 tests stay green.
