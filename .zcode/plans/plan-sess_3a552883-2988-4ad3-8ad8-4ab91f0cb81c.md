# Фича «Импорт фото → пиксель-арт»

## Концепция (лучший вариант)

Кнопка «Импорт» в TopBar (+ drag&drop фото на холст и Ctrl+V из буфера) открывает модальное окно с живым превью. Пользователь настраивает конвертацию и нажимает «Импорт» — изображение ложится на холст как **обычные ячейки с индексами палитры** (`doc.cells`), после чего редактируется всеми существующими инструментами. Вся конвертация — чистая функция в движке; коммит — одно undo-действие.

## Конвейер (новый чистый модуль `src/engine/importImage.ts`)

1. **Декодирование**: `createImageBitmap(file)` (в диалоге).
2. **Вписывание в холст** (выбор в диалоге): «Заполнить (обрезать)» / «Вписать (прозрачные поля)» / «Растянуть» / «Под размер изображения» (холст ресайзится под пропорции фото, клампится в `MAX_SIZE`). Даунсемпл box-усреднением в буфер `cols*sub × rows*sub` (учитывает sub-детализацию 1–3).
3. **Эффекты**: яркость / контраст / насыщенность (слайдеры −100…100) — простые пиксельные операции.
4. **Квантование цвета** (режимы): «Текущая палитра документа», готовый пресет из `PALETTES` (PICO-8, Game Boy, C64, Sweetie 16…), «Авто» — median cut на N цветов (слайдер 2–64, полученная палитра становится палитрой документа). Сопоставление — ближайший цвет по взвешенному RGB-расстоянию.
5. **Дизеринг**: «Нет», Ordered Bayer 2/4/8 (переиспользуем матрицы `BAYER2/4/8` из `fillpatterns.ts`), Floyd–Steinberg, Atkinson (serpentine-скан для FS). Прозрачность (<128 альфы) → пустая ячейка 0.
6. **Пиксель-скейл** (слайдер 1–4): каждый сэмпл занимает блок scale×scale ячеек — «крупный пиксель» для стилизации.

Ограничение v1: импорт только на квадратной сетке; для hex/triangle/radial в диалоге — уведомление и выключенная кнопка.

## Диалог `src/components/ImportDialog.tsx`

Каркас копирует `ProjectsDialog.tsx` (backdrop, Escape, ✕). Слева — превью-канвас (nearest-neighbor апскейл, переключатель «Оригинал/Результат», перерасчёт на смену опций с rAF-дебаунсом). Справа — контролы: существующие `Slider`, `CheckRow`, `Chip` из `ui.tsx`; select палитры; чипы дизеринга. Кнопки «Отмена» / «Импорт».

## Коммит в store (`src/state/store.ts`)

Новое действие `importPixels({cols, rows, palette, cells, resize})`: при режиме «под размер изображения» — `resizeDoc`, затем замена `palette` и `cells`, один `set()` → бесплатный undo/redo (zundo) и автосохранение. По образцу `paintCells` (store.ts:468).

## Точки входа

- **TopBar.tsx**: кнопка-иконка рядом с Projects + рендер диалога (паттерн `projectsOpen`, TopBar.tsx:23/220).
- **CanvasStage.tsx**: `onDragOver`/`onDrop` на обёртке холста — брошенный файл открывает тот же диалог.
- **App.tsx**: глобальный `paste`-обработчик (файл из буфера → диалог). Состояние диалога (`bitmap`) живёт в App и передаётся TopBar/CanvasStage.
