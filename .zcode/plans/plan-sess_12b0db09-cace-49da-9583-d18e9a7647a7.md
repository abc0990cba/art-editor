# Больше дизер-эффектов с настройками + пресеты размеров холста

## A. Новые паттерны (+8, всего станет 16) — `src/engine/fillpatterns.ts`
- `bayer16` — сверхмелкий упорядоченный дизер (рекурсивное расширение матриц уже есть)
- `checker` — блочная шахматка (крупнозернистый Байер-2)
- `grid` — сетка-«окно» (плотность = толщина линий)
- `hatch` — двойная диагональная штриховка
- `zigzag` — зигзаг-ряды (масштаб = амплитуда и шаг)
- `bricks` — кирпичная кладка со швами (плотность = толщина швов)
- `rings` — концентрические кольца вокруг точки клика
- `ign` — interleaved gradient noise (шум ровнее и «дорогlook» обычного, детерминированный)

## B. Индивидуальные настройки паттернов
- `FillStyle` += `scale` (1–6, множитель плитки: полосы, точки, шахматка, сетка, штриховки, зигзаг, кирпич, кольца) и `grain` (1–4, размер блока шума: noise, ign).
- `patternAt(id, x, y, t, { scale, grain, seed })` — кольца берут anchor из seed (точка клика).
- В панели fill слайдеры Scale/Grain появляются только у соответствующих паттернов (множества `SCALED_PATTERNS` / `GRAIN_PATTERNS`).
- Панель настроек инструмента получает прокрутку (`max-h` + `overflow-y-auto`) — чипов станет 16.

## C. Пресеты размеров холста — новый `src/engine/sizes.ts` + TopBar
- Группы по популярным пропорциям с optgroup в селекте: **1:1** (16/32/48/64/128/256/512), **4:3**, **3:2**, **16:9**, **21:9**, **2:1**, **10:9 Game Boy**, **8:7 NES**.
- У каждого размера — чётный и **нечётный** вариант (+1×+1; у 512 нечётная пара 511, чтобы не выходить за MAX_SIZE). Нечётная сетка имеет центральную строку/столбец — на них и садится симметрия.
- Текущий размер подсвечивается в селекте, произвольный размер показывается как сейчас (placeholder-опция).
