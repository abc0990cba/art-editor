# Второй режим «Вектор»: vtracer V1 + cutout/без-дырок + centerline + пресеты

Скоуп: TS-порт пайплайна vtracer V1 в `engine/` (wasm `@visioncortex/vtracer` — эталон в тестах), трассировка без дырок (cutout + holes: fill), centerline-трассировка (Zhang–Suen + Schneider), пользовательские пресеты, mosaic с общими рёбрами, архитектурные хуки (публичные стадии, defs/pattern в compose, вход «маски вместо RGBA»). Второй режим = переключатель «Пиксели | Вектор» в топ-баре; автосейв работы в IndexedDB.

## Реализация (этапы; после каждого — фидбэк-луп: format → lint → arch:check → knip → tsc → test; тексты коммитов предлагает агент, коммитит человек)

1. `docs/vectorization-research.md` — ресёрч + дизайн гибридов (дизер→вектор через маски; centerline + дизер-текстуры).
2. Движок `src/engine/trace/`: `params.ts` (параметры V1 + holes + centerline + пресеты) → `quantize.ts` (иерархическая кластеризация) → `binary-layer.ts` (контуры + Suzuki–Abe, holes keep/fill) → `simplify.ts` (RDP) → `fit-curves.ts` (Schneider) → `compose.ts` (stacked/cutout, defs-хук, path_precision) → фасад `trace.ts`; юнит-тесты на синтетике (кольцо, шахматка, градиент), bench + PERFLOG.
3. Паритет-харнесс: devDep `@visioncortex/vtracer` (пин 0.6.x, если есть на npm), структурное сравнение на фикстурах + снапшоты своего вывода.
4. `centerline.ts`: threshold → Zhang–Suen → скелетный граф → цепочки → RDP → Schneider → stroke-пути, толщина из distance transform; тесты (диагональ/крест/круг).
5. `mosaic.ts`: общие рёбра смежных регионов (общая кривая фиттится один раз); тест «два региона — кривые совпадают»; деградация в cutout при риске.
6. Воркер `features/vectorizer/trace.worker.ts` + `state/vector.slice.ts` + `state/vector-presets.slice.ts` + хук `use-vector-trace` (дебаунс, отмена, прогресс).
7. Storage: `DB_VERSION` 5→6, сторы `vectorJobs` (автосейв работы) и `vectorPresets`; wiring в `store.effects.ts` + загрузка при старте.
8. UI `features/vectorizer/`: переключатель «Пиксели | Вектор» (топ-бар + more-menu), `vector-workspace`, `vector-preview` (зум/пан/шторка), `vector-params-panel` (пресеты, tracer-свитч, секции параметров), импорт (drop/paste/клик), экспорт SVG + копирование, i18n `vector.*` (en+ru).
9. Мост «Векторизовать» из export-popover (`renderPng` → `vectorHandoff`) + тест входа «маски вместо RGBA» (дизер-палитра → маски → трассировка).
10. Финал: design-review по чеклисту, все гейты зелёные.

## Вне скоупа (осознанно)

ML-векторизация, очередь изображений, полноценный экспорт дизера как `<pattern>`-заливок (хук defs заложен), визуальный редактор путей.
