# Change `add-project-library`: библиотека проектов в IndexedDB с галереей и превью

Через OpenSpec: propose → apply → archive. Автосохранение текущего холста (`glyph.doc`) и ручной экспорт JSON-файлов остаются как есть — библиотека добавляется поверх.

## Хранилище: `src/storage/projects.ts` (IndexedDB)

- База `glyph-editor`, стор `projects` (keyPath `id`, индекс по `updatedAt`).
- Запись: `ProjectEntry { id, name, createdAt, updatedAt, thumbnail: dataURL, doc: ProjectJSON }`.
- API: `listProjects()` (по убыванию даты), `saveProject(entry)`, `loadProject(id)`, `deleteProject(id)`; `newProjectId()` через `crypto.randomUUID` с fallback.
- Деградация: если IndexedDB недоступен (тесты/приватный режим) — in-memory Map, API не меняется.

## Превью: `renderThumbnailDataURL(doc, maxSide = 320)` в `engine/png.ts`

Тот же пайплайн, что у PNG-экспорта (drawGeometry на offscreen canvas), масштаб так, чтобы большая сторона ≈ 320px, `toDataURL('image/png')`. Фон документа включается, шахматка — нет.

## UI: `ProjectsDialog.tsx` + кнопка в топбаре

- Топбар: кнопка **Projects/Проекты** (иконка папки) открывает модальный диалог (Esc закрывает).
- Диалог:
  - **Сохранить текущее**: поле имени + кнопка Save (serialize текущего doc + thumbnail + метки времени).
  - **Сетка карточек**: превью, имя (inline-rename), дата обновления; действия на карточке: **Open / Duplicate / Rename / Delete** (delete с inline-подтверждением).
  - **New project**: сброс на `defaultDoc()` (новый store-экшен `newDoc`, undo-очистка истории).
  - Состояния: загрузка, пустая библиотека, ошибка хранилища.
- **Защита от потери работы**: при Open/New, если на холсте есть закрашенные клетки — inline-подтверждение «текущий холст будет заменён» до применения.
- Открытие: `loadDoc(deserialize(entry.doc))` (существующий экшен) + закрытие диалога. Автосохранение продолжает следить за текущим холстом как раньше.
- i18n: `projects.*` EN/RU.

## Тесты

- Юнит: чистые хелперы хранилища (сортировка по дате, генерация имени дубликата, normalize имени) с in-memory фолбэком; `newDoc` сбрасывает документ.
- Браузерный смоук: save → перезагрузка страницы → проект в галерее с превью → open → duplicate → rename → delete; обе темы.

## Порядок

Артефакты OpenSpec → `storage/projects.ts` + thumbnail → диалог/топбар/store/i18n → тесты и смоук → архивация + финальный прогон (lint/tsc/vitest/build).
