# Halftone: режимы dirty/grunge винтажной печати

## Новые опции (секция Texture → эффект Halftone)

Семь новых ползунков + переиспользуемый `angle`. Все по умолчанию **0** → текущий вид не меняется, пока ползунки не тронуты. Вся случайность детерминирована от `seed` (кнопка Randomize уже есть в UI).

| Опция | Что делает |
|---|---|
| **Screen angle** (поле `angle`, 0–180°) | Поворот сетки точек. Дефолт 45° — диагональный растр, как на референсе. Туда же направляется ramp |
| **Ramp** (0–100) | Плавный перепад тона: размер точек нарастает вдоль угла (на референсе именно так) |
| **Jitter** (0–100) | Случайное смещение каждой точки от узла решётки |
| **Variation** (0–100) | Случайная вариация размера каждой точки |
| **Wobble** (0–100) | Неровные рваные края точек (шум по контуру круга) |
| **Merge** (0–100) | Соседние точки сливаются в кляксы («растекание чернил») |
| **Dropout** (0–100) | Пропадающие точки, сгруппированные шумом в пятна (протёртая печать) |
| **Spray** (0–100) | Мелкие брызги-сателлиты между точками |

## Механика слияния (ключевое)

Фрагменты текстуры — дырки в compound-path с `evenodd`, поэтому перекрывающиеся круги как отдельные подпути дали бы XOR-артефакт. Решение: точки собираются в массив, соседние по сетке (у которых `r1+r2` почти сходятся, порог от Merge + вероятностный гейт) объединяются union-find в кластеры, и каждый кластер эмитится как **один** замкнутый контур — «звёздное объединение» (полярный max-радиус от центроида по ~20 лучам + шумовая рябь от Wobble). Одиночная точка при Wobble=0 остаётся текущим двухдуговым кругом (вывод байт-в-байт совпадает с сегодняшним).

## Изменения по файлам

1. **`src/engine/doc.ts`** — 7 новых полей `TextureSettings` (jitter, variation, wobble, merge, dropout, spray, ramp: 0–100, дефолт 0) + дефолты в `defaultDoc()` + равенство в `sameElementStyle`.
2. **`src/engine/texture.ts`** — основная работа:
   - `regionTextureFragments` (pixels/outline): поворот решётки на `angle` (границы перебора расширяются на |cos|+|sin|), размер точки с учётом ramp/variation, dropout через `valueNoise` (пятна, не россыпь), jitter с проверкой `fits()`, сбор → кластеризация → эмиссия (circleFleck / wobbly-полигон / star-union blob) + spray-брызги.
   - `fieldTextureFragments` (metaball): те же опции через общие хелперы, чтобы все режимы рендера велись одинаково.
   - Новые хелперы: `wobblyCirclePath`, `starUnionBlob`, кластеризация. Случайность — только из `mulberry32(hash2(I, J, seed…))`, как сейчас.
3. **`src/components/SettingsPanel.tsx`** — для halftone: показать слайдер угла (подпись «Screen angle») и группу из 7 новых слайдеров; снять текущие скрытия.
4. **`src/engine/project.ts`** (`deserializeTexture`) и **`src/engine/presets.ts`** (`normalizePresetConfig`) — парсинг/клампинг новых полей; отсутствие поля в старых данных → 0.
5. **`src/i18n/en.ts` + `ru.ts`** — подписи и описания (label + .desc) для всех новых опций, обоих языках.
6. **`src/engine/texture.test.ts`** — тесты: нулевые дефолты дают прежний вывод; детерминизм при jitter>0 (одинаковый seed → одинаковый вывод, разный → разный); merge уменьшает число подпутей; dropout убирает точки; wobble меняет контур; ramp меняет размеры направленно; smoke-тест metaball-пути.

Store (`patchTexture` / `restyleSelection`) менять не нужно — `Partial<TextureSettings>` прокидывается автоматически.

## Совместимость

- Новые ползунки по нулям — существующие проекты не меняются, **кроме одного**: halftone начнёт уважать `angle` (дефолт 45°), поэтому старые halftone-работы отрисуются с поворотом сетки на 45° — как на вашем референсе. Если это нежелательно, сделаю отдельный слайдер с дефолтом 0 (старые проекты не изменятся).
- Тесты «halftone ignores the seed» останутся зелёными: при нулевых опциях случайность на вывод не влияет.
