⚡ Features

One editor — from the single cell to a living recipe

Pixel art, dithering and vector in one app: the canvas preview and the SVG export are built by the same geometry engine — the vector is exactly what you see on screen.

🖼️

Canvas up to 4096×4096

Any grid from 1×1: Game Boy, NES and 16:9 presets; wheel zoom, panning, checkerboard.

✏️

Around 30 drawing tools

From pencil and fill to spiral and gear — each with its own parameters.

🏁

Dither fills

22 patterns — Bayer, halftone, blue noise, void-and-cluster — with click-anchored gradients.

📸

Photos → pixel art

23 dithering algorithms and 22 palettes: from PICO-8 and C64 to ZX Spectrum.

🫧

Living cell shapes

28 forms, per-corner rounding and metaballs: neighbors merge into liquid.

❄️

Symmetry

Radial up to 24 axes, kaleidoscope, diagonal 8-way — in every tool.

🧩

Node recipes

A source → modifier → style chain (19 operations) that lives with the canvas.

🪄

Raster → vector

vtracer tracing and gradient fits: clean SVG with a live preview.

💾

Lossless export

SVG from the engine that draws the canvas; PNG up to 16×; autosave into IndexedDB.
