# Нодовая система — руководство

Нодовая система превращает объект из «намазанных пикселей» в **живой рецепт**: вы собираете
цепочку нод (источники → модификаторы → рампы → стили), и содержимое объекта пересчитывается
при каждой правке любой ноды. Это как Shader Nodes в Blender или Effects в After Effects —
только вместо картинки на входе и выходе — **сетка пикселей** вашего холста.

## Как открыть

Новые проекты создаются на сетке **128×128**; пресеты-рецепты масштабируются под текущий
размер холста автоматически. Редактор нод открывается поверх холста или рядом с ним
(сплит-режим с перетаскиваемым разделителем); внизу и справа — полосы прокрутки для
навигации, кнопки «Вписать» и «Рука» помогают ориентироваться в графе.

## Как открыть

1. Выделите объект на холсте инструментом «Выделение» (V) — или выберите его в панели «Слои».
2. В правой панели появится секция **«Граф объекта»** → нажмите «Создать граф».
3. «Открыть в редакторе» (или иконка нод в топбаре) открывает **большое нодовое пространство** —
   отдельный экран с карточками и проводами, как Node Editor в Blender.

## Как это устроено

Поток данных идёт сверху вниз по графу:

```
источник (рисует пиксели)
   ↓
модификаторы (преобразуют пиксели: сдвиг, массив, зеркало)
   ↓
рампа (перекрашивает по позиции — градиент)
   ↓
стиль (наводит внешний вид: скругления, metaball, текстура)
```

- **Источники** создают пиксели. Параметр `mode` решает, как вписать их в то, что уже есть:
  `add` — дорисовать поверх, `subtract` — вырезать, `intersect` — оставить только пересечение.
- **Модификаторы** преобразуют накопленное: `Offset` сдвигает, `Linear array` клонирует
  по линии, `Circular array` раскладывает копии по окружности, `Symmetry` зеркалит
  (mirrorX/mirrorY/quad/diag8/radial).
- **Рампы** перекрашивают: `Gradient` тянет градиент между двумя цветами палитры
  под заданным углом.
- **Стили** не трогают пиксели — они задают, как пиксели отрисовать: `Render mode`
  (обычные пиксели / контур / metaball), `Pixel shape` (скругления, размер), `Metaball`
  (сила слияния), `Texture` (зерно, grunge, полутон).

Цвета нод — обычные hex (например `#e63946`). Если цвета нет в палитре документа,
он добавится туда автоматически при расчёте.

**База графа — краска объекта.** Собственная краска объекта всегда является неявным первым
входом: стилевые ноды «одевают» её, рампы перекрашивают, источники дорисовывают поверх.
Нужен объект с нуля — сотрите старую краску ластиком или очистите объект.

## Рецепты

### Круговой массив из эллипса
```
source.ellipse (cx:8, cy:8, rx:3, ry:3)
   ↓
mod.arrayCircle (count: 6, cx: 8, cy: 8)   ← 6 копий по окружности
   ↓
ramp.gradient (angle: 45, from: 1, to: 3)  ← плавная перекраска по диагонали
   ↓
style.render (metaball)                    ← копии мягко сливаются
```

### Зеркальный узор
```
source.rect (x:0, y:0, w:6, h:6)
   ↓
mod.symmetry (mode: quad)                  ← четыре копии по углам
   ↓
style.pixel (radius: 0.4)                  ← скруглённые пиксели
```

### Контур с зерном
```
source.shape (shape: star, w: 12, h: 12)
   ↓
style.render (outline)                     ← силуэт вместо отдельных пикселей
   ↓
style.texture (effect: grain, amount: 60)
```

## Редактор нод (большое пространство)

- **Фон-сетка**: тяните мышкой — панорама; колесо — зум.
- **Карточки** перетаскиваются за заголовок; позиция сохраняется в проекте.
- **Провода**: потяните от **выхода** (справа) ноды к **входу** (слева) другой —
  создастся связь. Несколько проводов в один вход складываются вместе.
  Клик по проводу выделяет его, `Delete` — удаляет.
- **Селектор объекта** сверху: переключайтесь между графами разных объектов —
  массивы на одном, зеркала на другом.
- **Упорядочить** раскладывает карточки слоями по потоку.
- Циклы (замкнутые круги связей) запрещены — при импорте такое звено отбрасывается.

## Пресеты-примеры (в редакторе нод)

В тулбаре редактора есть селектор **«Пресеты…»** — выбираете рецепт, и он собирается в графе
текущего объекта (масштабируется под размер холста). Дальше правьте параметры и смотрите,
как меняется результат. В комплекте:

| Пресет | Что демонстрирует |
|---|---|
| Цветок — круговой массив | ellipse + Circular array + Gradient + metaball |
| Узор — зеркало ×4 | Rectangle + Symmetry (quad) + скругление |
| Снежинка — diag8 + зерно | Ellipse + Symmetry (diag8) + Texture (grain) |
| Полосы — линейный массив | Rect + Linear array + вертикальный Gradient |
| Решётка — массив ×2 | цепочка из двух Linear array (сетка по двум осям) |
| Кольцо — вычитание | два Ellipse, mode: subtract + Texture (halftone) |
| Полумесяц — вычитание со сдвигом | вычитание круга со смещённым центром |
| Линза — пересечение | mode: intersect + градиент по горизонтали |
| Точки по кругу + градиент | 12 копий мелкого круга + рампа по высоте |
| Сыр — три вырезания | цепочка из трёх вычитаний + Texture (grunge) |
| Метаболл-капли | три круга сливаются при высокой силе metaball |
| Звезда с зерном — контур | source.shape (star) + Render mode (outline) + grain |
| Слияние метаболлов | три круга + нода Metaball (strength 90): капли тянутся и сливаются |
| Мишень — кольцо + ядро | вычитание, затем добавление: концентрические круги |
| Лепестки — массив + зеркало | Circular array + Symmetry (mirrorY) + outline |
| Решётка — точки | цепочка двух Linear array: сетка точек 4×4 |
| Звезда в круге — пересечение | shape star + Ellipse (mode: intersect) |
| Шестерёнка — градиент + зерно | source.shape (gear) + Gradient (135°) + Texture (grain) |

## JSON и AI

Кнопки редактора:
- **Node registry** — машинная схема ВСЕХ нод: операции, параметры, типы, диапазоны,
  дефолты. Это готовая tool-схема для AI-агента: отдайте её модели вместе с задачей,
  и она вернёт граф.
- **Graph JSON** — текущий граф объекта.
- **Import graph** — вставьте граф из JSON; он проходит валидацию: неизвестные операции
  сохраняются, но пропускаются (с предупреждением), параметры клампятся по схеме.

Граф — обычный JSON:
```json
{
  "graphVersion": 1,
  "nodes": [
    { "id": "n1", "op": "source.ellipse", "params": { "cx": 8, "cy": 8, "rx": 3, "ry": 3, "color": "#e63946" } },
    { "id": "n2", "op": "mod.arrayCircle", "params": { "count": 6, "cx": 8, "cy": 8 } },
    { "id": "n3", "op": "ramp.gradient", "params": { "angle": 45, "from": 1, "to": 3 } },
    { "id": "n4", "op": "style.render", "params": { "renderMode": "metaball", "connectivity": "edge" } }
  ],
  "edges": [ { "from": "n1", "to": "n2" }, { "from": "n2", "to": "n3" }, { "from": "n3", "to": "n4" } ]
}
```

## Как добавить новую ноду (для разработчиков)

Одна функция `defineNode` в файле семейства `src/engine/nodes/nodes/*.ts` — схема параметров
и чистая функция `evaluate`. Редактор, AI-схема и конформанс-тест подхватят её автоматически.
Домены: `raster` (карта ячеек), `style` (внешний вид), `vector` (зарезервирован для контуров).
