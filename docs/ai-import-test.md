# Спайк: импорт SVG-фич в Adobe Illustrator (этап 0)

Откройте [samples/ai-import-test.svg](../samples/ai-import-test.svg) **двумя способами** и
сравните: 1) в браузере (эталон), 2) в вашем Adobe Illustrator («Файл → Открыть» и, отдельно,
«Поместить» на холст). Проставьте наблюдения в колонку «Наблюдение» — эта таблица определяет,
какие конструкции разрешены в AI-safe профиле экспорта градиентной трассировки.

| # | Конструкция | Ожидание в браузере | Наблюдение в Illustrator | Вердикт (AI-safe?) |
|---|---|---|---|---|
| 1 | `linearGradient`, `gradientUnits="userSpaceOnUse"`, 3 стопа | плавный красный→оранжевый→зелёный | | |
| 2 | `radialGradient` + `gradientTransform` (translate/rotate/scale → эллипс) | синий эллиптический градиент с белым центром, повёрнут | | |
| 3 | `stop-opacity` (0→1) | фиолетовый, растворяющийся вправо | | |
| 4 | `clipPath` (круг) | градиент обрезан по кругу | | |
| 5 | `mask` с радиальной градиентной маской | красный фон, проявляющийся к центру | | |
| 6 | `mix-blend-mode: multiply` | оранжевый квадрат затемняет синий (тёмный шоколадный) | | |
| 7 | `mix-blend-mode: screen` | фиолетовый квадрат осветляет тёмный фон | | |
| 8 | `plus-lighter` на 3 путях (Гуро-треугольник) | гладкий RGB-градиентный треугольник | | |
| 9 | `radialGradient` со `stop-opacity`-рампой (сплат) | жёлтое пятно, растворяющееся к краю | | |

## Что уже известно из ресёрча (проверить на практике)

- `mix-blend-mode` (6, 7) и тем более `plus-lighter` (8) при импорте SVG в Illustrator
  **теряются** — эффект молча пропадает. Если это подтвердится: слои-сплаты остаются
  source-over (секция 9 — это рабочая форма слоёв движка), а Гуро-треугольники не
  экспортируются в AI-safe профиле.
- Секции 1–5 и 9 — ожидаемо надёжные: это основа экспорта градиентного трейсера.
- Conic-градиент в SVG не существует вовсе (вне таблицы).

## Решения, которые принимает эта таблица

1. Если 1–5 и 9 живы — текущий экспорт движка (paths + `linearGradient`/`radialGradient` +
   `stop-opacity`) можно считать AI-safe без изменений.
2. Если 5 (маска) не живёт — движок и так её не использует (слои рисуются тем же контуром
   региона), ничего не меняется.
3. Если 9 не живёт (редко) — стопы прозрачности слоёв заменить на несколько колец
   непрозрачных путей (деградация качества слоёв).
